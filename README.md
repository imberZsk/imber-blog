# Imber Blog

基于 Next.js 16 的个人技术博客与 AI 学习知识库，集中沉淀 AI 应用开发、Agent、RAG、前端工程和开发工具实践。

## 主要内容

- 技术文章、知识地图与学习路径
- MDX 内容与 Sandpack 在线代码示例
- 项目作品集与 AI 工具实践
- 深色模式、全文导航和响应式阅读体验

## 技术栈

- Next.js 16、React 19、TypeScript
- Tailwind CSS 4、Framer Motion、GSAP
- MDX、Sandpack、Markmap

## 本地开发

```bash
pnpm install
pnpm dev
```

访问 <http://localhost:3000>。

## 质量检查

```bash
pnpm lint
pnpm build
```
