# 19. 进阶学习

> 来源：[大模型应用工程化](https://time.geekbang.org/space/wiki/LLM_App_Engineering)

这套大模型应用工程化承接前面的 Python 笔记助手，用 Kimi Code 帮助项目从能运行，走向可验证、可恢复和可持续迭代。

18 篇内容放在一起，其实是一条很完整的软件交付链路。

前4篇先处理任务与开发基础。

从 Vibe Coding 走向可验证工作，把模糊需求改写成输入、输出、边界和验收标准。然后用 Git、 diff、提交、分支与检查点，让每次修改都可以查看、比较和撤回。任务继续被拆成可验证小步，页面、业务、模型与存储之间也有了明确边界。

中间6篇建立信息与反馈系统。

项目约定、文档和上下文工程，让 Agent 每次看到正确的信息，而不是把所有资料一股脑塞进去。测试、调试与代码审查要求根据证据修复。AI 应用评测又把代码正确和回答可靠分开，通过固定题集检查检索、引用、语义与资料不足。日志、Trace 与成本则帮助定位一次失败究竟发生在哪一步。

后面6篇进入 Agent 运行环境。

工具与权限边界区分读取、写入、执行、敏感资料和外部副作用。Skills、脚本与 MCP 分别处理工作说明、确定性操作和外部连接。最小 Harness 把需求、上下文、工具、检查、状态与边界组合起来。 有限 Loop 定义完成条件、预算、停机规则和人工入口。长任务通过交接记录支持断点续做，多 Agent 则处理有限并行、文件归属、交付接口与集成成本。

最后2篇回到交付。

发布前检查依赖和数据兼容，准备版本与回滚，再通过一次完整项目迭代，把需求、修改、验证、中断恢复和迁移模板全部串起来。

这套知识库里有4个判断特别值得留下。

一个任务完成，不是 Agent 说完成了，而是有机器或人工可以核对的证据。

上下文工程不是提供越多信息越好，而是让正确、最新、与当前任务有关的信息进入正确步骤。

自动化不是放开权限让 Agent 自己跑，而是为读取、写入、执行和外部副作用设置不同边界。

Loop 也不是无限重试，它需要完成条件、预算、停机规则和人工升级入口。

这四个判断，已经把大模型应用从原型带到了工程系统门口。

但知识库里的贯穿项目毕竟是个人笔记助手，适合把方法走完整。进入企业 Agent 场景后，同样的方法会面对更大的规模和更高的风险。

工具不再只有少量本地操作，而可能连接搜索、代码仓库、数据库、工单、内部知识系统与外部服务。每个工具都需要注册、Schema、权限、审计、超时、重试和降级。任务也不再只是一次项目迭代，而可能持续几十分钟甚至更久。状态怎样保存，Checkpoint 怎样恢复，长上下文怎样压缩，工具结果怎样整理，异常怎样升级，都需要专门设计。

评测也会从固定题集扩展到执行轨迹。除了最终答案，还要判断规划是否合理、工具选择是否正确、 失败是否恢复、多 Agent 是否真的带来收益。到了生产环境，还会增加模型网关、版本、监控、回放、灰度、回滚、成本与多租户等问题。

知识库已经搭好了骨架。下一步，是让这副骨架承受更复杂的任务和更真实的生产压力。

这也是为什么想在这里推荐「AI Agent 全栈工程师训练营」。大模型应用工程化已经讲清楚需求、上下文、测试、Trace、权限、Harness、Loop、长任务、多 Agent 和交付，这门课与它的关系，不是重复概念，而是把这些工程方法放进六个更完整的 Agent 项目。

课程用 14 周覆盖 LLM 与 Prompt、RAG、Agent Loop、Memory、Skill、Context Engineering、 Agent Eval、Tracing、MCP 与生产部署。

Agent 工具调用基础设施项目会搭建 ToolRegistry、ToolSchema、JSON Schema 或 Pydantic 校验、权限分级、审计、超时、重试、降级、MCP Client 与 Trace。Codebase Agent 项目会实现 Planning、文件搜索与修改、测试执行、日志读取、自动修复、人工确认、沙箱、状态管理与 Checkpoint。

Codebase RAG 项目会加入代码索引、关键词与向量混合检索、Rerank、项目级记忆、长文件压缩、 任务摘要、恢复和引用追溯。Multi-Agent 与 Eval 项目会继续处理多角色协作、Skill 注册、 Benchmark、LLM-as-Judge、人工评测、Trace Analysis 和回归测试。

生产运维项目则加入模型网关、Redis、PostgreSQL、VectorDB、监控、回放、版本、灰度、回滚与成本治理。收官项目基于 DeerFlow 搭建深度研究平台和新一代软件工厂。

知识库教你把一个项目做稳，课程继续训练怎样把一套 Agent 系统做完整。
