# 2. 安装与首次启动

> 来源：[Qoder](https://time.geekbang.org/space/wiki/Qoder_Tutorial)

这一章的目标很简单：**把 Qoder 装到你的电脑上，并且成功登录。**

我知道「安装」这两个字常常让人心里一紧——尤其是对不常碰命令行的人来说，怕出错、怕报错看不懂。别担心，我会把每一步都掰开揉碎讲清楚：在哪打开终端、敲什么、回车后会看到什么、万一报错怎么办。你只要找到**自己操作系统对应的那一节**，从头照着做就行，其他系统的部分可以直接跳过。

## 2.1 开始之前：确认你的电脑符合要求

在动手前，先花一分钟确认两件事，能帮你避开绝大多数坑：

- **系统**：macOS、Linux、Windows 都支持。如果你用的是 Windows，我强烈建议你后面走 **WSL2** 那条路（2.5 节会讲为什么），体验会顺滑很多。
- **芯片架构**：arm64（比如苹果的 M 系列芯片）或 amd64（大多数 Intel/AMD 电脑）都行，不用特意去查，正常电脑都满足。
- **Node.js（可选）**：如果你打算用 npm 的方式安装，需要 Node.js 20 或更高版本。不过我们下面用的是官方的一键脚本，**不需要你提前装 Node.js**，所以你暂时可以忽略这一条。

确认完毕，我们开始。

---

## 2.2 macOS 用户看这里

**第一步：打开「终端」。**

终端就是那个能让你用文字命令电脑的窗口。打开方式有两种，任选其一：

- 按下 `Command（⌘）+ 空格键`，屏幕中间会弹出一个搜索框（叫 Spotlight），在里面输入 `终端` 或 `Terminal`，回车。
- 或者打开「访达（Finder）」，进入「应用程序」→「实用工具」文件夹，双击里面的「终端」。

打开后，你会看到一个窗口，最后一行停在一个闪烁的光标处，前面通常长这样：`你的用户名@电脑名 ~ %`。这就是在等你下命令了。

**第二步：粘贴安装命令并回车。**

把下面这一整行复制到终端里，然后按回车：

```
curl -fsSL https://qoder.com/install | bash
```

这行命令在干嘛？简单说：`curl` 是一个「从网上下载东西」的小工具，它把 Qoder 的官方安装脚本从 `https://qoder.com/install` 下载下来，然后用 `|`（管道符）把脚本交给 `bash` 去执行。整个过程是全自动的，你只需要等它跑完。

> 小提示：往终端里粘贴，用 `Command（⌘）+ V`。粘贴后记得按回车。

**第三步：看它跑完。**

回车后，屏幕上会滚动一些文字——那是它在下载、解压、配置。这中间可能会问你一两次问题（比如要不要把命令加到环境变量里），**一般情况下照着默认、按回车或输入 `y` 确认即可**。耐心等它停下来，直到光标重新回到闪烁状态。

**第四步：验证是否装好。**

为了确认安装成功，敲这一行并回车：

```
qoder --version
```

如果它回给你一个版本号（比如 `qoder 1.x.x` 之类），恭喜你，装好了！

如果它说 `command not found: qoder`（找不到命令），别慌，通常是因为环境变量还没生效。**最简单的解决办法是：关掉当前终端窗口，重新开一个，再试一次 `qoder --version`。** 绝大多数情况这样就好了。

装好之后，先别急着用，跳到 **2.6 节** 完成登录。

---

## 2.3 Linux 用户看这里

Linux 上的流程和 macOS 几乎一模一样，因为大家用的都是同一个安装脚本。

**第一步：打开终端。**

不同桌面环境快捷键略有差别，最通用的是按 `Ctrl + Alt + T`，通常就能直接弹出终端。如果不行，可以在应用菜单里搜索「Terminal」或「终端」。

**第二步：执行安装命令。**

```
curl -fsSL https://qoder.com/install | bash
```

含义和 macOS 那节讲的一样：下载官方脚本并执行。回车后等它跑完，中间若有确认提问，按默认（回车或 `y`）即可。

**如果报错说找不到 `curl`**：有些精简版 Linux 默认没装 curl。你可以先装它，再回来执行上面的命令。根据你的发行版选一条：

- Debian / Ubuntu 系：

  ```
  sudo apt update && sudo apt install -y curl
  ```
- Fedora / RHEL 系：

  ```
  sudo dnf install -y curl
  ```

（`sudo` 的意思是「用管理员权限执行」，敲完回车后它可能会让你输入开机密码。注意：**输密码时屏幕上不会显示任何字符，这是正常的**，盲打完按回车就行。）

**第三步：验证。**

```
qoder --version
```

出现版本号就成功了。若提示 `command not found`，同样先关掉终端重开一个再试；Linux 上有时需要重新加载配置文件，可以执行 `source ~/.bashrc`（如果你用的是 zsh，则是 `source ~/.zshrc`）。

装好后跳到 **2.6 节** 登录。

---

## 2.4 Windows 用户看这里（PowerShell 方式）

Windows 上有两条路可走：一是直接用 **PowerShell**（这一节），二是用 **WSL2**（下一节，我更推荐）。如果你只是想快速装好、且主要用命令行，这一节就够了；如果你想要更接近 Linux 的开发体验，可以直接跳到 2.5。

**第一步：打开 PowerShell。**

- 右键点击屏幕左下角的「开始」按钮（那个 Windows 图标），在弹出的菜单里找到「Windows PowerShell」或「终端（Terminal）」，点它。
- 或者按 `Win + R`，输入 `powershell`，回车。

打开后是一个蓝色或黑色的窗口，最后停在类似 `PS C:\Users\你的用户名>` 的提示符处，等你输入命令。

**第二步：执行安装命令。**

复制下面这一行，粘贴进 PowerShell（右键即可粘贴），然后回车：

```
irm https://qoder.com/install.ps1 | iex
```

这里的 `irm` 和 `iex` 是 PowerShell 里的命令简写：`irm`（Invoke-RestMethod）负责从网上把安装脚本下载下来，`iex`（Invoke-Expression）负责把它执行掉。作用和 macOS/Linux 那条命令是一样的，只是换成了 PowerShell 的写法。

**如果弹出「禁止运行脚本」之类的报错**：Windows 出于安全考虑，默认可能不允许运行脚本，报错信息里会出现 `Execution Policy`（执行策略）字样。解决办法是，先执行下面这行来放开当前用户的限制：

```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

它会问你是否确认，输入 `Y` 回车即可。然后再重新执行上面的 `irm ... | iex` 安装命令。

> 如果你更习惯用传统的命令提示符（CMD），也可以用这条命令安装：
>
> ```
> curl -fsSL https://qoder.com/install.cmd -o install.cmd && install.cmd
> ```

**第三步：验证。**

```
qoder --version
```

出现版本号即成功。若提示找不到命令，关掉 PowerShell 重新打开一个再试（让环境变量重新加载）。

装好后跳到 **2.6 节** 登录。

---

## 2.5 Windows 用户看这里（WSL2 方式，推荐）

先解释一句：**WSL2 是 Windows 官方提供的「在 Windows 里跑一个真正的 Linux」的功能。** 装好它之后，你就相当于在 Windows 电脑上开了一个 Linux 子系统，可以在里面用和 Linux 一模一样的命令。

为什么推荐这条路？因为大量的开发工具、教程、命令都是围绕 Linux/macOS 生态设计的，在 WSL2 里你能获得和它们完全一致的体验，将来遇到各种教程也能直接照抄命令，少踩很多 Windows 特有的坑。

**第一步：安装 WSL2。**

用管理员身份打开 PowerShell（右键「开始」按钮 → 选择「Windows PowerShell（管理员）」或「终端（管理员）」，如果弹出权限确认，点「是」），然后执行：

```
wsl --install
```

这条命令会自动帮你开启所需的功能，并安装一个默认的 Linux 发行版（通常是 Ubuntu）。

**第二步：重启电脑。**

安装完成后，**你需要重启一次电脑**，让 WSL2 真正生效。这一步别偷懒，重启是必须的。

**第三步：设置 Linux 的用户名和密码。**

重启后，通常会自动弹出一个 Ubuntu 的窗口，提示你创建一个用户账号。按提示：

- 先输入一个你想用的用户名（英文小写即可，比如 `zhangsan`），回车；
- 再输入密码，回车。**注意：输密码时屏幕上不会显示任何字符（连星号都没有），这是 Linux 的正常行为**，别以为没输进去，盲打完回车就行；
- 它会让你再输一次密码确认。

设置完，你就进入了 Linux 的终端，提示符长这样：`你的用户名@电脑名:~$`。

**第四步：在 WSL2 里安装 Qoder。**

从这里开始，你就完全按照 **Linux 的方式** 来做了。在这个 Ubuntu 终端里执行：

```
curl -fsSL https://qoder.com/install | bash
```

如果提示找不到 `curl`，先装一下：

```
sudo apt update && sudo apt install -y curl
```

装好后验证：

```
qoder --version
```

出现版本号就成功了。以后每次要用，就打开这个 Ubuntu（WSL）终端即可。

接下来进入 **2.6 节** 登录。

---

## 2.6 首次登录：让 Qoder 认识你

无论你用的是哪个系统，装好之后都要做一次登录，Qoder 才知道「你是谁、可以用它的服务了」。

登录方式很自然：**先进入任意一个项目文件夹，然后运行 `qoder`。**

比如，你可以先随便建个练习文件夹（下一章我们会正式建项目，这里只是先跑通登录）：

- macOS / Linux / WSL2：

  ```
  mkdir ~/qoder-hello && cd ~/qoder-hello
  qoder
  ```
- Windows PowerShell：

  ```
  mkdir $HOME\qoder-hello; cd $HOME\qoder-hello
  qoder
  ```

敲下 `qoder` 回车后，它会在终端里启动，并**引导你完成登录**——通常是给你一个链接或者一段提示，让你用浏览器授权，或者输入账号信息。你只需要**照着屏幕上出现的中文提示，一步一步来**即可。因为登录界面可能会随版本更新略有变化，所以我这里不写死每一步，但请放心，它的引导足够清晰，跟着走就能完成。

登录成功后，你就正式拥有了一个随时待命的 AI 工程师。

## 2.7 日后升级与卸载

软件总要更新。Qoder 升级很简单，两种方式任选：

- 直接用它自带的升级命令：

  ```
  qoder update
  ```
- 或者重新跑一遍安装脚本，加个强制覆盖的参数（macOS / Linux / WSL2）：

  ```
  curl -fsSL https://qoder.com/install | bash -s -- --force
  ```

至于卸载，如果哪天你不需要它了，删除对应的可执行文件和配置目录即可；具体路径可以查阅官方文档，这里就不展开了——毕竟我猜你装上之后就舍不得卸了。
