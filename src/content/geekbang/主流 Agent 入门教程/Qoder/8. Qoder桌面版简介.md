# 8. Qoder桌面版简介

> 来源：[Qoder](https://time.geekbang.org/space/wiki/Qoder_Tutorial)

本章选定 Qoder IDE，不把独立 Qoder 产品与 IDE 合称 Desktop / IDE。请从官方产品矩阵进入 Qoder IDE 下载页，选择明确支持当前系统的安装包，并记录版本。

打开第 7 章已提交的 ledger 副本，先核对项目路径、分支、Python 解释器，再让 IDE 只读说明测试入口。在集成终端运行 `python -m unittest discover -s tests -v`，然后做一项 README 修改并查看 diff。

同一账号不保证 CLI 与 IDE 的本地配置、会话、模型和权限自动同步。分别确认这四项；没有被官方承诺或实际验证的同步行为，不作为课程前提。项目文件通过相同目录或 Git 共享，不依赖会话同步。

参考：[Qoder 官方产品与文档](https://docs.qoder.com/)。
