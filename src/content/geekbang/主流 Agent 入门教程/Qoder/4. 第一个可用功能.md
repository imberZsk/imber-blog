# 4. 第一个可用功能

> 来源：[Qoder](https://time.geekbang.org/space/wiki/Qoder_Tutorial)

## 4.1 准备起点

把 [ledger-starter](exercise-assets/ledger-starter/) 复制到自己的 ledger 目录，使用 Python 3.10+。macOS/Linux 运行 `python3 -m venv .venv` 并 `source .venv/bin/activate`；Windows 用 `py -m venv .venv` 后激活，或直接使用 `.venv\Scripts\python.exe`。确认 `python --version` 和 `git --version`；本课参考验收使用 unittest，无需装 pytest。

初始化 `git init -b main`，先看 .gitignore 排除了 data 和 reports，再提交起点。

## 4.2 交给 Qoder 的接口契约

```
先阅读 README、fixtures/september.json 和 tests/test_contract.py，只出计划。
实现根目录 ledger.py，Python 标准库，入口 python ledger.py。
全局 --data 指定 JSON 路径，默认 data/records.json。
add 必须接受 --amount（元、正数、最多两位小数）、--type（收入/支出）、--category、--date（YYYY-MM-DD）、--note。
存储数组，每条字段 id、amount_cents（整数分）、type、category、date、note；ID 递增。
数据不存在按空数组；坏 JSON 或非法字段给出明确错误并非零退出，不覆盖原文件。
本章先实现 add、list；summary/report 在后续阶段完成。
测试使用临时目录，不能读取个人账目。退出计划状态并确认权限后才修改实现。
```

需求不再随生成结果改变。查看计划后先实现 add/list，再核对实际 diff。卡住时可看 [参考实现](exercise-assets/ledger-reference/)，但先解释差异，不能跳过验收。

## 4.3 固定日期，得到可手算的数据

下面在新的 `data/course-september.json` 中运行一次，重复运行会重复追加，已有数据时先换一个新的实验文件名：

```
python ledger.py --data data/course-september.json add --amount 8000 --type 收入 --category 工资 --date 2026-09-01
python ledger.py --data data/course-september.json add --amount 35 --type 支出 --category 餐饮 --date 2026-09-02
python ledger.py --data data/course-september.json add --amount 12 --type 支出 --category 交通 --date 2026-09-03
python ledger.py --data data/course-september.json list
```

预期恰好三条，整数分分别为 800000、3500、1200，月份均为 2026-09。使用固定日期使任何月份跟学都得到同一结果。非法金额 0.001 应报错且文件不变。
