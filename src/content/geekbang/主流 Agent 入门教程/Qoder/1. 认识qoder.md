# 1. 认识qoder

> 来源：[Qoder](https://time.geekbang.org/space/wiki/Qoder_Tutorial)

在动手之前，我们先花几分钟聊聊天，搞清楚一件事：**Qoder 到底是个什么东西，它凭什么能帮我们写代码。**

我知道你可能已经迫不及待地想敲命令了。但相信我，这一章花的时间，会在后面帮你省下更多的时间——因为只有当你明白手里这件工具「擅长什么、不擅长什么」，你才知道什么时候该把活儿交给它，什么时候该自己盯紧一点。

## 1.1 先把话说白：Qoder 是什么

一句话概括：**Qoder 是一个会写代码的 AI 工程师，就住在你的电脑里。**

它不是那种你问一句、它答一句，然后你还得自己把代码复制粘贴回项目的聊天机器人。Qoder 更进一步——它能**直接读懂你整个项目**，能**自己动手改文件、跑命令、看报错、再修正**，像一个坐在你旁边、随时能接管键盘的同事。

举个最直观的例子。假设你的程序报了一个错，屏幕上一大片红色的堆栈信息，看得人头皮发麻。传统做法是你自己一行行读、猜哪里出了问题、上网搜。而在 Qoder 里，你可以直接把报错甩给它，说一句「帮我看看这是怎么回事」。它会去读相关的代码文件，定位到真正出问题的那一行，告诉你原因，然后（在你同意之后）把修复写好。

这就是它和普通 AI 聊天最大的区别：**它不只给建议，它能真的把事情做完。**

## 1.2 那它具体能帮你做哪些事

我们来把它的能力落到几个你迟早会遇到的场景上：

- **从零写功能。** 你描述需求——「我要一个能记录收支的小工具」——它帮你把代码结构搭起来，把第一版功能实现出来。我们这本教程的主线，干的就是这件事。
- **读懂陌生代码。** 接手了一个别人写的项目，几百个文件，完全不知道从哪看起？你可以直接问它「登录逻辑在哪」「这个函数被谁调用了」，它会替你翻遍代码库给出答案。
- **调试排错。** 前面说的，把报错交给它，它帮你找根因、给修复。
- **重构。** 代码能跑，但写得乱、想优化结构？它能在你「有测试兜底」的保护下，安全地帮你整理。
- **写测试。** 很多人懒得写测试，Qoder 可以帮你补上，而且写得又快又全。
- **自动化和杂活。** 批量改文件、生成文档、跑一系列命令……这些重复劳动，交给它最省心。

你会发现，这些能力有个共同点：**它们都发生在「一个真实的项目」里，而不是空中楼阁。** 所以我们不打算空讲功能，而是直接上手做一个项目，让你在做中学。

## 1.3 Qoder 有好几种「长相」，该用哪个

Qoder 不是一种东西，它有几种不同的产品形态，就像同一个人可以穿正装、也可以穿运动服——内核是同一个，但适配的场合不同。搞清楚它们的区别，你就知道自己该穿哪套。

**① Qoder CLI —— 住在终端里的 AI（本教程的主角）**

这是 Qoder 的命令行形态。你在终端里敲一个 `qoder`，就把它唤醒了，然后你们在一个项目目录里对话、协作。

它适合谁？

- 习惯泡在终端里的人，敲命令比点鼠标还快；
- 需要连远程服务器干活的人（服务器上通常没有图形界面，CLI 是唯一选择）；
- 想把 AI 嵌进自己现有工作流、甚至写进脚本里自动跑的人。

它的特点是**轻、快、灵活**，没有花哨的界面，一切都在文字的来回之间完成。这也是为什么我们选它当主角——把 CLI 玩明白了，你对 Qoder 的理解就打通了任督二脉。

**② Qoder IDE —— 一个完整的图形化编辑器**

这是一个独立的桌面应用，长得像一个代码编辑器：左边是文件树，中间是代码，旁边有一个 AI 对话面板。你能用鼠标点点点，也能看到代码高亮、diff 对比等等。

它适合谁？

- 刚入门、对终端还有点怵的新手；
- 喜欢「所见即所得」、习惯图形界面的人；
- 从零开始一个新项目，想要一个一体化环境的人。

我们会把 Desktop 放到**最后一章**再介绍。原因是：CLI 是理解 Qoder 的地基，地基打牢了，再回头看图形界面会觉得「哦，原来就是把这些能力换了个壳」，学起来毫不费力。

**③ IDE 插件 —— 装进你已有的编辑器里**

如果你已经用惯了 VS Code、JetBrains 这类编辑器，一天都不想离开它们，那 Qoder 也提供了插件形态——把 AI 能力直接塞进你熟悉的工具里，不用换环境。

它适合谁？

- 已经有一套顺手的编辑器、不想推倒重来的人；
- 希望在现有项目里「就地」获得 AI 辅助的人。

**一张表帮你选：**

| 形态 | 长什么样 | 最适合的场景 |
| --- | --- | --- |
| **Qoder CLI** | 终端里的文字对话 | 命令行重度用户、远程服务器、脚本自动化、想深度理解 Qoder |
| **Qoder IDE** | 独立图形化编辑器 | 新手、喜欢图形界面、从零开发新项目 |
| **IDE 插件** | 装进 VS Code / JetBrains | 离不开现有编辑器、想就地加 AI 能力 |

> 说句掏心窝的话：这三种形态背后是同一套能力，你不用纠结「选错了怎么办」。我们先用 CLI 把基本功练扎实，等你熟了，无论切到 Desktop 还是插件，都是水到渠成的事。

## 1.4 我们这本教程怎么学

先跟你交代一下接下来的节奏，让你心里有数：

1. **第 2 章**，我们先把 Qoder 装到你的电脑上（无论你用 Mac、Linux 还是 Windows，都有对应步骤）。
2. **从第 3 章开始，我们正式启动实战项目「记账小管家」。** 你会先学会用 git 给项目「立规矩」——这是我特别想让你养成的好习惯，它会在你后面写错代码、想反悔的时候救你一命。
3. **第 4 到第 7 章**，我们一步步把这个记账工具做出来、修好、优化好、最后交付。每往前一步，你都会顺手学会一个 Qoder 的核心能力。
4. **第 8 章**，我们回头看一眼 Qoder Desktop，把三种形态彻底串起来。

关于命令，再啰嗦一句：**正文里的命令以 macOS / Linux 为主**，遇到 Windows（PowerShell 或 WSL2）不一样的地方，我会用醒目的方式单独标出来。你只需要认准自己系统对应的那一段，照着敲就行，不用被其他系统的命令干扰。
