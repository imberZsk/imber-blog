## 五、阶段 2：本地 HTTP API

发送：

```
实施 PLAN.md 的阶段 2，只新增 app.py。

必须满足 REQUIREMENTS.md 的固定路由，并支持：
python app.py --host 127.0.0.1 --port 8000

约束：
- 只允许 host 为 127.0.0.1；
- 使用 Python 标准库 HTTP 服务器；
- 查询参数错误返回 HTTP 400 和 error=invalid_request；
- 未知菜谱返回 HTTP 404 和 error=not_found；
- 数据损坏返回结构化 JSON，不向浏览器发送 Traceback；
- 暂时不要创建前端和 README；
- 不修改固定测试、检查器、需求和菜谱。

完成后运行 unittest，并实际启动服务器验证 /api/recipes 和一条带 servings 的详情请求，然后停下来。
```

如果 Claude 要启动服务器，确认绑定地址是 `127.0.0.1` 而不是 `0.0.0.0`。服务启动后，在另一个终端执行真实请求。

macOS、Linux 或 WSL2：

```
python3 -c "import json,urllib.request; data=json.load(urllib.request.urlopen('http://127.0.0.1:8000/api/recipes')); assert len(data)==6; print('PASS: API 返回 6 份菜谱')"
```

Windows PowerShell：

```
py -c "import json,urllib.request; data=json.load(urllib.request.urlopen('http://127.0.0.1:8000/api/recipes')); assert len(data)==6; print('PASS: API 返回 6 份菜谱')"
```

预期打印 `PASS: API 返回 6 份菜谱`。停止服务器后再继续；如果端口被占用，临时改用 `--port 8010`，并同步修改检查 URL。

## 关键排错

**测试一开始就通过**：确认你没有误在 `mealcraft-reference` 或旧项目中运行；主项目在复制实现验收包后、编写代码前应因模块缺失而失败。

**Claude 修改固定测试**：拒绝该修改并用 Git Diff 恢复到课程复制后的内容。测试与需求真的冲突时应先停止并核对，不应由被测实现自行放宽标准。

**发布检查提示连接失败**：先手工运行 `app.py`，确认没有语法错误、绑定 `127.0.0.1` 且接受 `--host`、`--port`。安全软件拦截时只允许本机回环测试。

**unittest 通过但网页没有菜谱**：这是为什么还要真实 HTTP 和浏览器验收。打开终端日志及浏览器开发者工具的 Network/Console，记录失败 URL 和状态码，再让 Claude 复现。

**源 JSON 哈希变化**：停止提交，查看 `git diff -- data/recipes`。换算必须基于深复制或新结构，不能把 `display_amount` 写回源文件。

## 十一、补齐输入与浏览器边界验收

参考快照已补齐以下边界，生成自己的实现时也应满足：

- JSON 的 `true` 不能作为整数份数或分钟数；食材名不能只含空白。
- 菜谱文件损坏属于服务端 `500 recipe_data_error`；非法参数为 `400 invalid_request`，不存在的菜谱为 404，分别验收。
- 菜谱内容只按文本显示。把测试菜谱名设为 `<img src=x onerror=alert(1)>`，页面应显示原样文字，不创建图片或执行脚本。
- API 错误或服务器停止时显示可见错误，并清空旧结果；恢复服务后重新筛选可重试。
- 连续改变筛选、快速切换详情时，最终界面对应最后一次选择，较早请求不能覆盖新结果。

复制 implementation-kit 后，在项目根目录运行 `python -m unittest discover -s tests -v`（macOS/Linux 可用已验证的 `python3`）。新增 `test_revision_boundaries.py` 验证输入和 HTTP 边界。浏览器三项仍需亲自操作；单元测试通过不能代替页面验收。

可选自动检查：安装 Node.js 后在合并好的项目根目录运行 `node tests/test-browser-boundaries.cjs`。它使用最小 DOM 替身检查文本渲染、请求乱序及 HTTP 错误，不代替真实浏览器的布局与交互验收。
