# 0. 学前须知

> 来源：[Claude Code](https://time.geekbang.org/space/wiki/Claude_Code_Tutorial)

> 版本基准：2026-09-29  
> 面向读者：第一次接触 Claude Code、愿意在终端中完成练习的中国初学者

这套教程只介绍 **Claude Code 命令行**，不讲桌面客户端或 IDE 扩展。你会用一个本地个人项目 **MealCraft** 走完调查、规划、修改、测试、验收和自动化，再用三个独立练习检验自己能否把方法迁移到别的项目。

完整学完后，你应该能够：

- 安装 Claude Code，并判断版本、认证和当前工作目录是否正确；
- 让 Claude 先调查和规划，再在明确边界内修改文件；
- 用权限、Sandbox、Git、测试和人工操作控制风险；
- 用 `CLAUDE.md`、Skills 和 Hooks 固化项目知识与重复流程；
- 实际连接一个本地 MCP、加载一个本地插件、调用一个受限 Subagent；
- 管理长会话与后台任务，并用 `claude -p` 完成受限、可验证的自动化。

主线预计需要 12～16 小时。不同系统、模型响应和终端经验会影响实际时间；文章长度不代表重要程度。

## 开始前要准备什么

\*\*本套教程配套代码文件：\*\*<https://gitee.com/geektime-geekbang_admin/ai-tutorial-material/tree/master/claudecode-materials>

你需要一台支持 Claude Code 的 macOS、Windows 或 Linux 电脑，以及可以使用的 Claude Code 账号或官方支持的 API/云提供方配置。第 2、3 篇会从安装和认证开始，不要求你提前安装 Python、Node.js 或准备代码项目。

课程会使用 Git 保存练习节点，并从第 5 篇开始使用 Python 3.11+。如果尚未安装，相关文章会给出检查方法和恢复路径。中国读者还可能遇到账号地区、网络或支付可用性限制；第 3 篇会解释官方登录、API 和第三方兼容网关的边界，但不会承诺某一种方式在所有地区都可用。

Claude Code 更新很快。遇到教程文字与本机界面不一致时，先记录版本，再查看：

```
claude --version
claude --help
```

进入交互会话后，输入 `/help` 查看当前可用命令。不要因为某个命令没有出现在旧截图里，就用作用相近但风险更高的参数代替。

## 第一部分：认识、安装和完成第一次闭环

这一部分结束时，你会在一个可丢弃目录中完成第一次调查、计划、文件修改和实际运行。

1. Claude Code 到底是什么  
   分清模型建议、CLI 权限和验证证据各自负责什么。
2. 在 macOS、Windows 和 Linux 上安装 Claude Code  
   安装并用版本与健康检查证明命令可用。
3. 登录、选择模型与配置连接方式  
   分清订阅登录、Console/API 计费与兼容网关的信任边界。
4. 第一次使用 Claude Code  
   在练习目录中完成“只读调查 → Plan → 修改 → `/diff` → 实际运行”。

## 第二部分：完成并保护 MealCraft 1.0

MealCraft 是一个只在本地运行的个人菜谱网站。练习素材会随相关文章放入 `exercise-assets/`；每篇都会给出复制起点、验证状态和重新开始的方法，不要求你临时拼出未知项目。

5. 规划 MealCraft 第一版  
   从固定 starter 出发，确定数据格式、范围、阶段和可观察的验收标准。
6. 完成 MealCraft 第一版  
   分阶段实现浏览、筛选和份数换算，并用测试与浏览器操作验收。
7. 先复现，再修复食材换算错误  
   在确定存在缺陷的版本上完成失败测试、最小修复、回归验证和 Diff 审查。
8. 权限、Sandbox 与安全配置  
   分清权限模式、规则和操作系统级隔离，并为导出功能验证路径边界。
9. 用 CLAUDE.md 教会 Claude 理解项目  
   用项目说明、路径 Rules 和实际会话验证长期上下文是否生效。

## 第三部分：长任务、扩展能力与自动化

先把基础工作流跑稳，再增加扩展。这里的 Skills、Hooks、MCP、插件和 Subagents 都会有真实文件、触发动作、预期结果和独立验证，不只停留在概念介绍。

10. 管理长任务：把 MealCraft 升级到 2.0  
    分阶段完成一周菜单和购物清单，并练习恢复、分支、压缩及后台 Agent。
11. 用 Skills 和 Hooks 固化工作流  
    创建可调用的周菜单 Skill，并让 Hook 在菜谱修改后执行确定性校验。
12. MCP、插件与代码智能  
    连接只读本地库存 MCP，把稳定能力打包成本地插件；代码智能作为选学边界。
13. 用 Subagents 隔离调查任务  
    创建只读审查 Agent、限制工具、检查结果并由主会话复核；Agent Teams 只作选学说明。
14. 使用 `claude -p` 实现受限自动化  
    正确区分工具白名单、免审批和 Bare Mode，验证退出码、结构化输出与预算边界。

## 第四部分：三个可重置的综合实战

这三篇不再增加大量新功能，而是检验你能否独立使用前面的工作方法。每个练习都会提供固定夹具和重置方法。

15. 修复个人博客的搜索问题  
    稳定复现异步竞态，比较两种方案并完成最小修复。
16. 批量升级旅行笔记格式  
    对模拟个人笔记执行盘点、Dry Run、小批量、全量、幂等和回滚验证。
17. 排查个人项目中偶发失败的测试  
    从三平台日志建立假设，把偶发失败变成确定性测试后再修复。

## 怎样选择学习路径

- **第一次使用 Claude Code：** 按 1～14 篇顺序完成，再至少选择一个综合实战。第 5 篇以后会复用前面留下的项目状态，不建议随意跳过。
- **已经用过其他编码 Agent：** 仍先完成第 4 篇，确认 Claude Code 的目录、权限和验证节奏，再从第 5 篇进入 MealCraft。
- **已有 Claude Code 基础：** 阅读第 8～14 篇，并用第 16 或 17 篇检查自己是否能处理权限、扩展和不确定问题。
- **只在排错时查阅：** 先到第 18 篇按症状定位，再回到对应正文；不要直接复制附录中的配置到重要项目。

## 练习时守住三条线

1. 第一次操作只在教程目录、练习副本或临时目录中进行；不要把真实笔记或唯一一份个人数据当实验素材。
2. Claude 报告“完成”不是验收。每次都查看实际文件、运行测试或亲自操作结果。
3. Checkpoint 适合短期试错，Git 或独立备份负责长期恢复；批量脚本、外部程序和部分 Agent 修改不能假设一定可由 `/rewind` 撤销。

准备好后，从第 1 篇开始建立正确的工作模型，再动手安装和修改项目。
