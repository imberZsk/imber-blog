# 12. acp接入编辑器

> 来源：[MiniMax Code](https://time.geekbang.org/space/wiki/MiniMax_Code_Tutorial)

## 12.1 先确认两端

先在普通终端验证 `mcode --version` 与登录／Provider；再在目标编辑器确认其版本支持 ACP。ACP 的 stdio 模式由编辑器启动子进程，并接管 stdin/stdout。

## 12.2 配置启动器

在编辑器的自定义 Agent 配置入口设置 command 为 mcode 的绝对路径，args 为 `["acp"]`，工作目录为当前项目。具体 JSON 外壳以该编辑器版本的 ACP 配置说明为准，不把 Zed 的配置复制到其他产品。

不需要先执行 `mcode acp &`。那会启动一份没有编辑器接管输入输出的进程；随后编辑器可能再启动第二份。手工 `mcode acp` 只用于查看启动错误，正常等待输入并不代表已与编辑器连接。

## 12.3 验收

在编辑器选择该 Agent，提交“只读取 README 并说明测试入口”。检查实际工具返回、项目目录和模型；再做一项可回滚的小修改并查看 diff。找不到程序时核对绝对路径及编辑器继承的环境；有进程不等于 ACP 握手成功。

参考：[MiniMax ACP 文档](https://agent.minimaxi.com/docs/cli/acp)。
