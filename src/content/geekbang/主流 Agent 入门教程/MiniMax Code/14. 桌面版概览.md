# 14. 桌面版概览

> 来源：[MiniMax Code](https://time.geekbang.org/space/wiki/MiniMax_Code_Tutorial)

## 14.1 平台与安装

以审核日官方发布页列出的 macOS、Windows 下载项为准。没有列出的 Linux AppImage／deb 不作为已发布产品讲解；Linux 学员可继续 CLI／ACP 路线。

## 14.2 打开同一个练习副本

在 Desktop 新建任务并选取 habitlog 练习目录，先只读核对 README、分支、测试入口。不要凭同一品牌或同一账号就假定 CLI 的会话、Provider、权限和本地配置都会同步。

## 14.3 一项小验收

先记录桌面应用版本与 CLI 的 mcode --version。选择一个 README 错别字，要求修改并运行相关检查，独立查看 diff。分别检查项目文件是否共享、会话是否能找到、模型是否一致；只有实际观察到的项目才标为同步，不共享的内容手动配置。

本章不重复 CLI 的安装、Git 和提交步骤，沿用第 5～6 章闭环。版本故障报告应标明是 Desktop 还是 CLI，二者源码和发行边界不同。

参考：[官方仓库与下载入口](https://github.com/MiniMax-AI/minimax-code)、[Desktop 文档](https://agent.minimaxi.com/docs/code)。
