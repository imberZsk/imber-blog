# 1. 认识TraeCode

> 来源：[TraeCode](https://time.geekbang.org/space/wiki/TraeCode_Tutorial)

## 第一章 认识 TraeCode

### 1.1 什么是 TraeCode？能做什么？

TraeCode 是一款**深度融合 AI 能力的开发工具**，覆盖从代码编写、项目理解、调试运行到变更管理的完整开发流程。它的核心思路是：你用自然语言描述需求，AI 智能体理解代码仓库、读取和修改文件、执行命令、生成和评审代码，帮你完成繁琐的开发任务，让你专注于更有价值的创造性工作。

一句话概括：**TraeCode 让 AI 不只是补全代码，而是参与需求拆解、代码生成、问题排查、重构优化和变更管理等真实开发环节。**

### 1.2 TRAE 产品矩阵一览

TRAE 企业版提供四类产品，适应不同使用习惯：

| 产品 | 形态 | 一句话定位 |
| --- | --- | --- |
| **TraeCode** | AI 原生 IDE（桌面应用） | 功能完整的 AI IDE，内置 IDE 模式与 SOLO 模式 |
| **TraeCode Plugin** | VS Code / JetBrains / Android Studio 插件 | 把 AI 编程能力注入你现有的 IDE，不改变习惯 |
| **TraeCode CLI** | 终端命令行工具 | 运行在本地终端里的编码 Agent，支持交互式 TUI 与非交互式命令 |
| **TraeWork** | 网页版 / 桌面版 / 移动端 App | AI 原生工作台，覆盖从专业开发到日常办公 |

### 1.3 各产品适合什么场景？

| 使用场景 | 推荐产品 | 原因 |
| --- | --- | --- |
| 日常编码，需要实时代码补全和快速问答 | TraeCode Plugin | 零迁移成本，装插件登录即用 |
| 处理多步骤复杂任务（测试修复、代码审查、重构） | TraeCode CLI | 支持多轮工具调用，适合复杂编排 |
| 在 CI/CD 中自动化代码任务 | TraeCode CLI（非交互模式） | `-p` 参数可直接执行并退出，融入流水线 |
| 想要完整的 AI 原生 IDE 体验 | TraeCode | 一个界面完成全流程工作 |
| 非开发岗位的日常办公（写报告、做 PPT、整理数据） | TraeWork | Work 模式面向全产研办公 |

### 1.4 为什么本教程以 CLI 为主线？

- **贴近终端开发流程**：从理解需求、修改代码、运行测试到评审变更，都能在终端连续完成。
- **可自动化**：支持非交互模式，能融入脚本和 CI 流程，这是 CLI 的杀手锏。
- **学习成本低**：一条命令安装，开箱即用。
- **核心能力覆盖最全**：代码理解、修改、测试、Git、MCP、插件、技能、自定义命令——CLI 都能玩转。

> **提示**：TraeCode CLI 目前仅 **TRAE 企业版旗舰版套餐** 可用，且默认使用 Max 模式，请注意用量消耗。本教程假设你已具备相应账号权限。
