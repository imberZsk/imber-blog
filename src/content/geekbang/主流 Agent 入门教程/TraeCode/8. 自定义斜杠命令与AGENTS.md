# 8. 自定义斜杠命令与AGENTS

> 来源：[TraeCode](https://time.geekbang.org/space/wiki/TraeCode_Tutorial)

## 8.1 把已验证的约定写进 AGENTS.md

在项目根目录创建 AGENTS.md，记录 Python 版本、src/cli\_app.py 入口、整数分单位、--data 参数、测试命令和真实数据保护规则。先让助手读取现有实现和测试再拟稿，删除尚未实现的命令。新会话要求复述关键约束，再用实际 diff 和测试验收。

## 8.2 先保存普通任务模板

CLI 2.0 官方扩展页提供 /plugins、/skills、/mcp；旧 `.traecli/commands/*.md` 的自动加载协议未在当前参考中确认，因此本课不依赖它。建立 docs/prompts/review.md，内容包括：比较基准、允许读取的范围、检查正确性与回归风险、每项发现的文件位置及触发输入、允许零发现。使用时明确把文件内容作为本次审查任务提供，不能假定写文件后 /review 自动出现。

再建立 docs/prompts/changelog.md：根据指定两个提交之间的 git log 与 diff 生成变更草稿，区分功能、修复与兼容性；不把未提交改动写成已发布内容。通过后才人工写入 CHANGELOG。

## 8.3 何时迁移成扩展

先在两个会话里验证模板能重复使用，再按本机 /plugins 或 /skills 的帮助安装成正式扩展。扩展目录、frontmatter 和参数以同代官方规范为准；没有确认协议时保留普通 Markdown 流程，避免把旧路径写成最新保证。

参考：[CLI 2.0 扩展](https://docs.trae.cn/cli_tools-and-extensions)。
