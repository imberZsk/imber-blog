# 13. 速查表-模板-下一步

> 来源：[CodeBuddy](https://time.geekbang.org/space/wiki/CodeBuddy_Tutorial)

## 13.1 从问题找到入口

| 问题 | 回到哪里 |
| --- | --- |
| 安装、登录、版本与环境 | 第 1 章；先保存 codebuddy --version 与 --help |
| 上下文与会话 | 第 3 章；凭据不写进记忆 |
| 运行不了项目 | 第 4 章：目录、解释器、完整报错、最小修复 |
| 测试写完却没抓住缺陷 | 第 5～6 章：合同、边界与先红后绿 |
| 重构后行为变化 | 第 7 章：小步提交与特征测试 |
| 容器重建丢数据 | 第 8 章：DATABASE\_PATH 与持久卷 |
| 自动化误报成功 | 第 9 章：独立测试退出码与真实差异输入 |
| 条件规则不触发 | 第 10 章：paths、alwaysApply 和实际匹配验证 |
| 子代理、Skill、Hook | 第 11 章与配套 06-power-features |

## 13.2 只保留一份模板

规则模板以第 10 章为准，使用 paths，不再重复 globs 旧模板。子代理、Skill、Hook 的可复制文件统一在 materials-cbc/06-power-features；修改后同时更新说明与验收。不要把其他产品同名配置直接复制过来。

## 13.3 完成课程的证据

保存：第 4 章健康检查、账单修复前后边界测试、第 7 章行为对比、短链重启持久化结果、提交 Hook 的失败拦截结果。标注本机产品版本和操作系统；未登录或未部署的步骤明确留为待验证。

## 13.4 下一步

选一个自己的小项目复用“契约—最小实现—独立验收—提交”的流程。一次只增加一个能力；先证明它解决实际问题，再增加插件或子代理。
