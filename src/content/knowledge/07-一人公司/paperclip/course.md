# 《Paperclip 学习小册》· 学习路线与目录

> 一本带你从零开始，把「AI 员工团队」真正跑起来的实战小册。
> 适合：想用 AI Agent 自动化业务的独立开发者、创业者，以及对多 Agent 编排感兴趣的技术人。
> 不需要你懂多 Agent 编排理论，跟着章节一步步做就能上手。

---

## 这本小册讲什么

Paperclip 是**自治 AI 公司的控制平面（Control Plane）**——一句话：让你像开一家真公司一样，雇 AI Agent 当员工，给他们定目标、分任务、管预算，然后看着这家「零人工公司」自己运转起来。你的角色是董事会（Board），负责把关关键决策、盯进度、控成本。

这本小册的目标，是让你：

1. **看懂**：理解 Paperclip 到底解决什么问题、核心概念怎么咬合。
2. **跑通**：在本地把平台跑起来，建出第一家能干活的 AI 公司。
3. **用好**：吃透心跳、任务协作、技能、治理这些核心机制，能排查协作卡壳。
4. **上线**：把公司从本地玩具变成能长期运行、可部署、可控成本的真东西。

## 逐章学习目标

### 入门篇

#### 01 · 认识 Paperclip：把 AI 当员工招进来
- **学完你能**：用一句话向别人讲清 Paperclip 是什么、它和「又一个聊天机器人」的本质区别。
- **关键收获**：理解「控制平面」这个定位、「零人工公司」理念、为什么任务管理软件不够用。

#### 02 · 五分钟跑起来：本地启动你的控制台
- **学完你能**：在自己电脑上把 Paperclip 跑起来，打开 `localhost:3100` 看到控制台。
- **关键收获**：`npx paperclipai onboard` 与 `run` 的区别、内嵌 PostgreSQL、本地数据存在哪。

#### 03 · 六大核心概念
- **学完你能**：分清 Company、Agent、Issue、Heartbeat、Delegation、Governance 各自是什么、怎么咬合。
- **关键收获**：这一章是后面所有内容的「词汇表」，吃透它后面就不会晕。

#### 04 · 架构总览：控制平面 vs 执行平面
- **学完你能**：画出 Paperclip 的四层架构，说清「一次心跳从触发到落库」的完整流转。
- **关键收获**：理解「Paperclip 不运行 Agent，只编排 Agent」这条核心设计原则。

### 进阶篇

#### 05 · 创建你的第一家公司：从目标到 CEO
- **学完你能**：在 UI 里建出一家公司、写好目标、招出第一个 CEO Agent、搭起组织架构、设好预算。
- **关键收获**：一个「好目标」长什么样、为什么 CEO 适合用 Claude Code 当大脑、预算的软/硬上限。

#### 06 · Agent 与 Adapter：给每个员工选对「大脑」
- **学完你能**：看懂 `claude_local` / `codex_local` / `process` / `http` 四种适配器，知道什么场景选哪个。
- **关键收获**：Adapter 是 Paperclip 和 AI 运行时之间的桥；BYOB（自带大脑）理念。

#### 07 · 心跳机制：AI 员工如何「上班打卡」
- **学完你能**：说清心跳的 5 种触发方式、心跳协议的 9 个步骤、Agent 如何跨心跳「记住」上下文。
- **关键收获**：「记忆碎片」心理模型、session 持久化、为什么 Agent 不是常驻进程。

#### 08 · 任务系统与多 Agent 协作：Issue、签出与任务树
- **学完你能**：理解 Issue 状态机、原子签出（为什么会 409）、任务树如何把活追溯回公司目标、@提及如何唤醒队友。
- **关键收获**：多 Agent 协作卡壳的两大根因（任务树没挂好、没开 `wakeOnAssignment`）及排查思路。

#### 09 · 治理与审批：你是董事会
- **学完你能**：配置雇人审批、CEO 策略审批，知道董事会能强制暂停/接管哪些操作，看懂活动审计。
- **关键收获**：人类在自治系统里的「方向盘」——批准什么、放权什么。

#### 10 · 技能系统：给 Agent 装「外挂」
- **学完你能**：写出一个合格的 `SKILL.md`，理解技能如何被按需加载、注入到 Agent 运行时。
- **关键收获**：把 description 写成「路由逻辑」、技能要聚焦单一职责、第三方技能的安全注意事项。

### 实战篇

#### 11 · 实战：从 0 搭一家内容公司（OpenAgent）
- **学完你能**：跟着完整案例，亲手搭出一家「AI Agent 开发者学习与分享社区」公司，让团队自动协作产出。
- **关键收获**：把前 10 章串成一条可复现的实操链路，体会「设目标 → 招人 → 放手」的完整闭环。

#### 12 · 成本控制与可观测性：钱花在哪、活干得怎样
- **学完你能**：用看板实时追踪每个 Agent 的任务进度与 token 花费，设好预算告警与硬停。
- **关键收获**：解决传统 AI 工具「干了啥、花了多少钱」难复盘的痛点；订阅制下成本为何显示 0。

#### 13 · 部署与上线：从本地玩具到长期运行
- **学完你能**：分清几种部署模式，会用 Docker 部署、用 Tailscale 做私有访问，理解密钥与存储怎么管。
- **关键收获**：从 `local_trusted` 本地可信模式走向可长期、可远程访问的部署。

#### 14 · CLI 与 API 速查手册
- **学完你能**：随手查到常用 CLI 命令和核心 REST API，写自定义脚本/适配器时不抓瞎。
- **关键收获**：一份能贴在显示器边上的速查表。

#### 15 · 避坑指南与最佳实践
- **学完你能**：避开新手最常踩的坑，知道一套让 AI 团队稳定产出的最佳实践。
- **关键收获**：全书常见错误 + 最佳实践的总集合，也是日常运营的「自检清单」。

## 怎么用这本小册

- **零基础**：从 01 顺序读到 11，每章都动手跟做，到第 11 章你已经能独立搭一家公司。
- **有基础、想直接干**：扫一眼 03（概念）和 04（架构），直接跳 05 + 11 上手，遇到机制不清再回查 06~10。
- **运营中遇到问题**：直接翻 08（协作卡壳）、12（成本）、15（避坑）这几章按图索骥。

> 全书坚持「示例驱动」：每章都给真实命令、真实 API 调用、真实配置，避免空话套话。
