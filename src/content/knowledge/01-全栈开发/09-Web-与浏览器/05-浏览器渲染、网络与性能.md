# Web 与浏览器（05） - 浏览器渲染、网络与性能

> 读完你能：沿导航、资源加载、渲染和交互时间线定位性能瓶颈，而不是只压缩 JavaScript 包。

## 核心知识清单

- DNS、TCP、TLS、HTTP 与缓存
- HTML 解析、DOM、CSSOM 与渲染树
- Layout、Paint 与 Composite
- preload、preconnect、defer 与资源优先级
- LCP、INP、CLS 与真实用户监控
- CSP、同源策略、CORS 与 Cookie 安全

## 关键路径

HTML 解析过程中阻塞脚本可能暂停 DOM 构建，CSS 影响渲染树；布局计算几何，绘制生成图层内容，合成把图层送到屏幕。性能优化应先用 Performance 和 Network 证明确切瓶颈，再决定减少请求、调整优先级、拆分主线程任务或稳定布局。

缓存需要区分强缓存和协商缓存。带哈希静态资源适合长期 `immutable`，HTML 需要较短策略以发现新版本。CORS 是浏览器读取限制，不是服务端认证；Cookie 会话同时配置 `Secure`、`HttpOnly` 和合适的 `SameSite`。

## 验收

- 用真实设备或节流环境记录 LCP、INP、CLS 和长任务。
- 每个优化前后使用同一页面、缓存状态和网络条件。
- 监控按版本和页面拆分，避免实验室平均分掩盖真实长尾。
