# Web 与浏览器（01） - 学习指南

> 先理解平台，再学习框架；HTML、CSS、JavaScript、网络和渲染机制决定所有 Web 应用的上限。

## 学习目标

- HTML 语义、表单、可访问性与渐进增强
- CSS 盒模型、布局、层叠、响应式与主题
- JavaScript 事件循环、内存、模块与异步
- 浏览器解析、渲染、缓存、安全与性能
- TypeScript 泛型、收窄、类型边界与构建

## 推荐顺序

先用语义 HTML 和 CSS 完成无脚本可读页面，再加入事件与异步；随后观察网络瀑布和渲染时间线；最后用 TypeScript 表达数据契约，而不是用类型断言掩盖未知值。

## 学完验收

- 能用键盘和读屏语义完成核心交互。
- 能解释一次事件、网络请求和页面渲染经过哪些队列与阶段。
- 能用泛型和联合类型表达 API 状态，并在运行时校验外部数据。
