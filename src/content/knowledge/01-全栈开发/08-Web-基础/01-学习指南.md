# Web 基础（01） - 学习指南

> 用浏览器中的一条真实请求串起页面语义、布局、脚本、类型、网络与运行时，不把 HTML、CSS 和 JavaScript 学成互不相干的语法表。

## 学习目标

- HTML、CSS、JavaScript 与 HTTP
- TypeScript 与运行时校验
- 浏览器事件、存储、性能与安全

## 推荐顺序

1. 先读页面到接口的完整链路，能区分 DOM、样式、事件与网络职责。
2. 再用 TypeScript 约束开发期数据，用 Schema 校验接口运行时数据。
3. 最后学习事件循环、存储和渲染性能，能够用 DevTools 定位问题。

## 学完验收

- 能解释一次表单提交从 DOM 事件到 HTTP 响应再到页面更新的过程。
- 能说明 TypeScript 为什么不能替代接口校验。
- 能用 Network、Performance 和 Storage 面板定位至少一种真实故障。
