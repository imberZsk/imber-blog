# Python（23） - 数据可视化

> 读完后，你应能解释“3.1 pyplot 状态机接口（plt.xxx）—— 像全局单例画布”，复现“3.2 面向对象接口（fig, ax）—— 像拿到 DOM 节点再操作”的最小实现，并用“4.1 折线图（趋势）—— ax.plot”检查结果与失败边界。

> 你在前端画图，第一反应是 ECharts / Chart.js / D3：给个容器、塞一份 `option` 配置、它就渲染出图。Python 这边对标的就是 **matplotlib**——数据科学界事实上的"画图标准库"，Pandas、NumPy 的结果几乎都靠它出图。本篇解决三个问题：怎么把一组数字快速画成折线/柱状/散点；matplotlib 那套"看起来很乱"的 API 到底分几种、该用哪种；以及在没有屏幕的后端服务器上怎么把图存成文件。

# 一、先建立前端锚点

| 你在前端这么做 | matplotlib 对应 | 说明 |
|----------------|-----------------|------|
| `import * as echarts from 'echarts'` | `import matplotlib.pyplot as plt` | 引入画图库 |
| `echarts.init(dom)` 拿到实例 | `fig, ax = plt.subplots()` 拿到画布+坐标系 | 创建图 |
| `chart.setOption({...})` | `ax.plot(x, y)` / `ax.bar(...)` | 往图里塞数据 |
| 浏览器自动渲染到页面 | `plt.show()`（弹窗）或 `fig.savefig(...)`（存文件） | 输出 |
| `arr.map(...)` 处理完数组再喂给图表 | `df.plot()`（Pandas 直接出图） | 数据→图一步到位 |

核心切入点：**matplotlib ≈ 后端版的 ECharts/D3**。差别在于——ECharts 是"声明式塞一份 option"，matplotlib 更像"命令式地往画布上一笔一笔画"。理解了这个差异，后面那套看着零散的 API 就顺了。

> 安装：`pip install matplotlib`。它常和 NumPy（第 20 篇）、Pandas（第 21 篇）一起用，画图的数据来源通常就是它们。

# 二、最小可用：三行画一条折线

```python
import matplotlib.pyplot as plt   # 约定俗成的别名 plt，几乎所有教程都这么写

x = [1, 2, 3, 4, 5]          # x：横坐标数据（比如月份）
y = [2, 5, 3, 8, 7]          # y：纵坐标数据（比如销售额）

plt.plot(x, y)               # 画一条折线，把 (x,y) 一一对应连起来
plt.show()                   # 弹出窗口显示这张图（脚本里会阻塞，直到关掉窗口）
```

对照你熟悉的 ECharts，本质是同一件事，只是 matplotlib 把"配置"拆成了一行行函数调用：

```javascript
// ECharts 等价写法：一份声明式 option 塞进去
chart.setOption({
  xAxis: { data: [1, 2, 3, 4, 5] },
  yAxis: {},
  series: [{ type: 'line', data: [2, 5, 3, 8, 7] }]
})
```

记住这个对照：**ECharts 是一份 option 对象，matplotlib 是一串 `plt.xxx()` 调用**，最后 `show()` 等价于 ECharts 渲染到 DOM。

# 三、关键：matplotlib 有两套 API，别学混

新手看 matplotlib 教程最容易懵，是因为网上代码混用了两种写法。务必先分清：

## 3.1 pyplot 状态机接口（`plt.xxx`）—— 像全局单例画布

`plt.plot()`、`plt.title()` 这类直接挂在 `plt` 上的函数，背后操作的是一个**全局"当前图"**。你不用拿到任何对象，所有调用都默默作用在那块隐藏的画布上。

```python
import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [4, 5, 6])   # 往"当前图"画折线
plt.title("销售趋势")             # 给"当前图"加标题
plt.xlabel("月份")                # 给"当前图"加 x 轴标签
plt.show()                        # 渲染"当前图"
```

这种风格类比 JS 里操作一个**全局 canvas 单例**：你不传引用，函数内部自己找那块全局画布。写一次性脚本很爽，但多张图并存时容易画串。

## 3.2 面向对象接口（`fig, ax`）—— 像拿到 DOM 节点再操作

更推荐、也更可控的写法：先 `plt.subplots()` 拿到 `fig`（整张画布）和 `ax`（坐标系），之后所有操作都明确作用在 `ax` 上。

```python
import matplotlib.pyplot as plt

# fig：整张图（画布/窗口本身）；ax：里面的一个坐标系（真正画东西的地方）
fig, ax = plt.subplots()

ax.plot([1, 2, 3], [4, 5, 6])    # 明确往这个 ax 上画
ax.set_title("销售趋势")          # 注意：OO 接口用 set_xxx，不是 plt.title
ax.set_xlabel("月份")             # 给这个 ax 设 x 轴标签
plt.show()
```

这就像前端里 `const dom = document.getElementById('chart')` 拿到节点再操作，而不是依赖某个全局状态。**多子图、复杂布局、在函数里画图返回，一律用 OO 接口**。

| 状态机接口 | OO 接口 | 类比 |
|------------|---------|------|
| `plt.plot(...)` | `ax.plot(...)` | 全局 canvas vs 拿到的 DOM 节点 |
| `plt.title(...)` | `ax.set_title(...)` | 注意 OO 多了 `set_` 前缀 |
| `plt.xlabel(...)` | `ax.set_xlabel(...)` | 同上 |
| 适合：一次性脚本、Jupyter 速画 | 适合：多图、库代码、可控布局 | —— |

> 边界提醒：**两套 API 别在同一段代码里乱混**。新手常见错误是先 `fig, ax = plt.subplots()` 又去调 `plt.title()`，结果标题加到了"当前图"而不是你的 `ax` 上，看着没生效。本篇之后统一用 OO 接口。

# 四、四种最常用的图

数据可视化 90% 的场景就这几种。下面都用 OO 接口。

```python
import matplotlib.pyplot as plt

months = ["1月", "2月", "3月", "4月"]   # months：横轴分类标签
sales = [120, 200, 150, 280]            # sales：每月销售额
```

## 4.1 折线图（趋势）—— `ax.plot`

```python
fig, ax = plt.subplots()
# marker="o" 在每个数据点画圆圈；label 是图例文字
ax.plot(months, sales, marker="o", label="销售额")
ax.set_title("月度销售趋势")
ax.legend()      # 显示图例（要先在 plot 里给 label 才有内容）
plt.show()
```

## 4.2 柱状图（对比）—— `ax.bar`

```python
fig, ax = plt.subplots()
ax.bar(months, sales, color="skyblue")   # color 指定柱子颜色，可用颜色名或 #十六进制
ax.set_title("月度销售对比")
plt.show()
```

## 4.3 散点图（相关性）—— `ax.scatter`

```python
import numpy as np                  # 用 NumPy 造点随机数据（详见第 20 篇）

x = np.random.rand(50)              # x：50 个 0~1 的随机数
y = np.random.rand(50)             # y：另一组 50 个随机数

fig, ax = plt.subplots()
ax.scatter(x, y, alpha=0.6)        # alpha 是透明度 0~1，点重叠时能看出密度
ax.set_title("随机散点")
plt.show()
```

## 4.4 直方图（分布）—— `ax.hist`

直方图和柱状图不一样：柱状图是"每个分类一根柱"，直方图是"把连续数据切成若干区间(bin)，统计每段落了多少个"，用来看分布。

```python
import numpy as np

data = np.random.randn(1000)       # data：1000 个标准正态分布随机数

fig, ax = plt.subplots()
# bins=30 表示把数据范围切成 30 个区间，分别统计落入个数
ax.hist(data, bins=30, color="orange")
ax.set_title("数据分布")
plt.show()
```

| 图类型 | 函数 | 用来回答 | ECharts 里的 type |
|--------|------|----------|-------------------|
| 折线 | `ax.plot` | 随时间怎么变 | `line` |
| 柱状 | `ax.bar` | 各类别谁高谁低 | `bar` |
| 散点 | `ax.scatter` | 两个量有无相关 | `scatter` |
| 直方 | `ax.hist` | 数据怎么分布 | 无直接对应，需自己分桶 |

# 五、常见定制：标题、坐标、图例、多线

一张图常常要画多条线、加网格、调范围。这些都是 `ax` 上的方法：

```python
import matplotlib.pyplot as plt

months = ["1月", "2月", "3月", "4月"]      # months：横轴的月份分类标签
sales_a = [120, 200, 150, 280]      # sales_a：A 产品销售额
sales_b = [80, 160, 210, 190]       # sales_b：B 产品销售额

fig, ax = plt.subplots(figsize=(8, 4))   # figsize=(宽, 高)，单位英寸，控制图大小

# 在同一个 ax 上多次调用 plot，就是多条线叠加（类比 ECharts 的多个 series）
ax.plot(months, sales_a, marker="o", label="产品A")
ax.plot(months, sales_b, marker="s", label="产品B")

ax.set_title("产品销售对比")        # 标题
ax.set_xlabel("月份")               # x 轴标签
ax.set_ylabel("销售额(万元)")       # y 轴标签
ax.set_ylim(0, 300)                 # y 轴范围固定 0~300，避免自动缩放误导
ax.grid(True, linestyle="--", alpha=0.5)   # 加虚线网格，便于读数
ax.legend()                         # 图例：把上面两个 label 显示出来

plt.show()
```

要点：**多条线 = 在同一个 `ax` 上多次 `plot`**，每条给不同 `label`，最后 `ax.legend()` 一次性显示图例。这和 ECharts 往 `series` 数组里塞多项是一个意思。

# 六、显示 vs 保存：后端服务器没有屏幕

这是前端转后端最容易踩的点。`plt.show()` 是要"弹窗"的，但你的代码常常跑在**没有图形界面的服务器**上（比如 FastAPI 接口里生成报表图）。这时候不能 `show()`，要直接存成文件。

## 6.1 保存为图片

```python
fig, ax = plt.subplots()
ax.plot([1, 2, 3], [4, 5, 6])

# 存成 PNG。dpi 是分辨率（每英寸点数），越高越清晰、文件越大
# bbox_inches="tight" 自动裁掉多余白边，避免标题被切
fig.savefig("chart.png", dpi=150, bbox_inches="tight")
```

> 注意：`savefig` 要在 `show()` **之前**调用。因为 `show()` 在某些环境下会清空当前图，之后再 save 可能得到空白图。

## 6.2 无界面环境：切 Agg 后端

如果服务器连图形库都没装，`import matplotlib.pyplot` 可能直接报错或卡住。解决办法是在导入 pyplot **之前**指定一个不依赖屏幕的后端 `Agg`：

```python
import matplotlib
matplotlib.use("Agg")          # 必须在 import pyplot 之前调用！指定"只渲染到文件"的后端
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [4, 5, 6])
fig.savefig("server_chart.png")   # 服务器上只存文件，不弹窗
```

类比理解：浏览器里 ECharts 必须有 DOM 容器才能渲染；`Agg` 后端相当于给 matplotlib 一块"虚拟离屏 canvas"，画完直接导出图片，全程不需要真实窗口。

# 七、和 Pandas 联动：一行出图

实际数据分析里，数据基本都在 Pandas 的 DataFrame 里（第 21 篇）。DataFrame 自带 `.plot()`，底层就是调 matplotlib，省去手动取列：

```python
import pandas as pd
import matplotlib.pyplot as plt

# df：一张销售表，像加强版 Excel（index 是月份，列是不同产品）
df = pd.DataFrame(
    {"产品A": [120, 200, 150, 280], "产品B": [80, 160, 210, 190]},
    index=["1月", "2月", "3月", "4月"],
)

df.plot(kind="line", marker="o")   # kind 指定图类型：line/bar/scatter/hist 等
plt.title("销售对比")
plt.show()
```

`df.plot()` 会自动把每一列画成一条线、用 index 当横轴、列名当图例——相当于帮你把"取数据 + 配 series"一步做完。快速探查数据时首选它。

# 八、绕不开的坑：中文显示成方块 □□□

这是中文用户用 matplotlib 的第一个拦路虎：标题、标签里的中文全变成空心方块。**WHY**：matplotlib 默认字体不含中文字形，找不到就用方块占位。解决办法是显式指定一个系统里有的中文字体：

```python
import matplotlib.pyplot as plt

# 指定中文字体。不同系统字体名不同：
#   macOS 常用 "Arial Unicode MS" 或 "PingFang SC"
#   Windows 常用 "SimHei"（黑体）
#   Linux 可能需要先装字体（如 文泉驿）
plt.rcParams["font.sans-serif"] = ["Arial Unicode MS"]

# 修了中文字体后，负号又可能显示异常，这行把它扳回正常的 ASCII 负号
plt.rcParams["axes.unicode_minus"] = False

fig, ax = plt.subplots()
ax.plot([1, 2, 3], [-4, 5, -6])
ax.set_title("中文标题不再是方块")
plt.show()
```

`plt.rcParams` 是 matplotlib 的全局配置字典，类比前端的全局主题变量/CSS 变量——改一次，之后所有图都生效。

# 九、其他易踩的坑

1. **两套 API 混用导致设置不生效**（第三节已说，重复强调因为最常见）。拿了 `ax` 就一路 `ax.set_xxx`，别中途跳回 `plt.title`。

2. **`plt.show()` 在脚本里会阻塞**。它会卡住程序直到你手动关掉弹窗，循环里画多张图时尤其坑。批量出图请用 `savefig` 不用 `show`。

3. **忘了清理导致图越画越乱**。状态机接口下连续画多张图，新图会叠在旧图上。要么每次用独立的 `fig, ax = plt.subplots()`，要么 `plt.close(fig)` 关掉上一张释放内存（服务器里循环出图不关会内存泄漏）。

4. **Jupyter 里不用 `show()` 也能显示**。Notebook 环境自动渲染最后一个图对象，但写成 `.py` 脚本就必须 `show()` 或 `savefig()`，别把 Jupyter 习惯带到脚本里。

5. **直方图 `hist` 当成柱状图 `bar` 用**。`bar` 要你自己给好每根柱的高度；`hist` 是给它一堆原始数据、它自己分桶统计。搞反了画出来不对。

# 十、总结

matplotlib 是 Python 的画图标准库，心智模型对标 ECharts/D3，但风格从"塞一份 option"变成"一串 `plt.xxx()` / `ax.xxx()` 命令"。它有两套 API：`plt.xxx` 状态机（像全局单例 canvas，适合速画）和 `fig, ax = plt.subplots()` 面向对象（像拿到 DOM 节点，适合可控/多图），二者别混用。四种核心图：折线(plot)/柱状(bar)/散点(scatter)/直方(hist)。后端无界面环境用 `matplotlib.use("Agg")` + `savefig` 存文件；数据在 DataFrame 里时 `df.plot()` 一行出图最省事。

✅ 该掌握
- `import matplotlib.pyplot as plt` 是约定别名
- OO 接口 `fig, ax = plt.subplots()` → `ax.plot/bar/scatter/hist` → `ax.set_title/set_xlabel`
- 折线看趋势、柱状看对比、散点看相关、直方看分布
- 服务器出图：`matplotlib.use("Agg")`（在 import pyplot 前）+ `fig.savefig(...)`
- `df.plot(kind=...)` 直接从 Pandas 出图

⚠️ 易混淆
- 状态机 `plt.title` 和 OO `ax.set_title` 别混用，否则设置不生效
- `savefig` 要在 `show` 之前调，`show` 在脚本里会阻塞
- 中文变方块：设 `plt.rcParams["font.sans-serif"]`，并把 `axes.unicode_minus` 关掉
- `bar`（自己给柱高）≠ `hist`（给原始数据自动分桶）
- 循环出图记得 `plt.close()`，否则内存泄漏
