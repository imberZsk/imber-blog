# 前端框架（01） - 学习指南

> 以组件状态、数据获取、渲染位置和部署边界为主线选择框架，不按 API 数量判断“谁更强”。

## 学习目标

- Vue 与 React 应用架构
- Next.js 渲染、缓存与数据安全
- Electron、小程序与跨端边界

## 推荐顺序

1. 先掌握组件、状态、路由、表单和服务端数据的共同问题。
2. 再比较 Vue 与 React 的状态更新方式，而非逐个背 API。
3. 最后学习 Next.js 服务端边界与跨端容器的安全模型。

## 学完验收

- 能为一个 CRUD 页面划分本地状态、服务端状态和 URL 状态。
- 能解释 Server Component、Client Component 与 Route Handler 的信任边界。
- 能说明 Electron 渲染进程为什么不能直接获得完整 Node.js 权限。
