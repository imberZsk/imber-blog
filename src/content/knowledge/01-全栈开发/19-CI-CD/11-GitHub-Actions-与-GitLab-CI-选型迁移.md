# 二、平台对象与能力映射

GitHub Workflow、Job、Step 大致对应 GitLab Pipeline、Job、script，
Environment 与保护规则也有相似目标，
但 Runner 作用域、标签和执行器配置不同。
迁移不能只翻译 YAML，还要重建权限、制品、缓存和审批语义。

# 三、选型维度与组织约束

代码托管、合规地域、身份系统、Runner 网络、模板生态、制品仓库、审计和团队技能共同决定成本。
SaaS 降低控制面运维，自托管增强数据控制但要求升级、备份和安全响应能力。

# 四、双跑、证据对比与切换

先抽取平台无关脚本和制品契约，
再让两套流水线对同一提交双跑，
比较测试、digest、权限、耗时和部署结果。
切换前冻结旧平台写操作并保留回退窗口，按合规要求归档历史证据。
