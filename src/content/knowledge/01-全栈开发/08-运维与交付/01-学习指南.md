# 运维与交付（01） - 学习指南

> 从“本机能运行”走到“线上可发布、可观察、可回滚”，重点掌握交付链路，而不是背命令。

## 学习目标

- Linux 进程、端口与 Nginx 网络入口
- Docker、Kubernetes 与运行时配置
- CI/CD、制品、灰度发布与回滚
- 日志、指标、Trace、告警与全链路排障

## 推荐顺序

1. 先用进程、端口和 Nginx 理清请求如何进入应用。
2. 再把应用制作为不可变镜像，并区分构建配置与运行配置。
3. 使用 Kubernetes 声明副本、探针、滚动发布和资源限制。
4. 最后建立 CI/CD、可观测性、告警和回滚闭环。

## 学完验收

- 能沿着 DNS → LB/Nginx → Service → Pod → 数据库定位一次请求。
- 能解释镜像、容器、Deployment、Service 和 Probe 的职责边界。
- 能用同一个制品完成灰度、回滚，并用 Trace 和指标证明结果。
