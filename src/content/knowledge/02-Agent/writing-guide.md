# 小册写作标准（内部参考，非学习正文）

> 这份文档定义 04-52 篇重写后的统一结构、语气和 demo 对应规则。所有批次必须遵守。

## 1. 核心问题（为什么要重写）

旧版 04-52 是模板套壳：「为什么前端要学它」「上手路径」「常见坑」「完成标准」「面试官可能怎么问」「自测清单」「学习建议」七个段落几乎逐字相同，每篇只换了标题词。读者读 10 篇等于读 1 篇。

重写目标：**每一段都是这一篇独有的、具体的、可操作的内容。删掉所有可以套用到任意章节的废话。**

## 2. 语气与可读性

- 中文，前端视角类比，但类比要准确、点到为止，不强行套。
- 短句优先。一段讲一件事。
- 多用「具体例子 + 代码 + 表格」，少用抽象排比。
- 不要喊口号（「非常重要」「必修课」），用事实说话。
- 不堆叠 emoji 和感叹号。

## 3. 新文章结构（统一骨架）

```
# 标题

> 一句话目标：这一篇读完你能做出/讲清什么（具体，不空泛）

## 一个真实场景
用一个具体的业务/产品场景切入，让读者立刻知道这东西用在哪。
（这一段必须是本篇独有的，不能套模板）

## 核心概念（标题按内容自定，2-4 个小节）
真正讲清楚原理。能画流程就画 ASCII 流程；能列对比就用表格。
每个概念配一个最小、正确、能跑的代码片段。

## 配套 demo：跑起来看
明确指向 `demos/NN-slug/`，给出运行命令和预期输出。
解释 demo 里哪个函数/文件对应上面哪个概念。

## 工程上真正会踩的坑（本篇独有）
必须是这个主题特有的坑，不是通用废话。
例：13-流式响应 → 「SSE 断连后前端重复追加 token」；
    28-Function-Calling → 「模型把参数名拼错导致 schema 校验失败」。

## 一句话面试答法（仅在相关章节，1-2 条，具体）
不是「它解决从概念到落地的一个环节」这种空话。
给出真能背、能说的具体回答。

## 下一篇
`NN-xxx.md` + 一句话说明承接关系。
```

不是每篇都要有全部小节。Python 基础篇可以省「面试答法」；面试篇（49-52）主体就是问答库，结构另见第 6 节。

## 4. demo 目录约定

所有 demo 放在 `Agent/demos/` 下，每篇一个目录：

```
Agent/demos/
  05-python-basics/
    README.md          # 这个 demo 演示什么、怎么跑、预期输出
    main.py            # 入口，直接 python3 main.py 可跑
  28-function-calling/
    README.md
    main.py
  16-frontend-call-ai/
    README.md
    index.html         # 前端篇用 HTML/JS，浏览器打开即可
    server.py          # 配套最小后端（可选）
```

### demo 硬性要求

1. **零外部依赖优先**：能用 Python 标准库 / 浏览器原生 API 就不要装包。
2. **离线可跑**：不需要真实模型 API Key。用本地 mock model 模拟模型输出（参考现有 `agent-demo/src/agent/offlineModel.js` 思路）。
3. **可选真实 API**：如果演示真实调用有价值，用环境变量开关，`if not os.getenv("OPENAI_API_KEY"): 用 mock`。默认走 mock。
4. **一条命令跑通**：README 第一行就是运行命令。
5. **有预期输出**：README 里贴出跑完应该看到什么，读者能自检。
6. **代码注释遵守全局规范**：每个函数、每个变量、非显然的分支都要中文注释说明用途（见 CLAUDE.md）。

## 5. embedding/检索类 demo 的离线实现思路

不依赖真实 embedding API，用「词袋 + 余弦相似度」或「关键词加权打分」模拟语义检索，足够讲清原理。参考 `agent-demo/src/agent/tokenize.js` 的 `scoreText`。在 README 里明确写「真实项目用 OpenAI/bge embedding，这里用简化打分演示流程」。

## 6. 面试篇（49-52）特殊结构

主体是**真实问答库**，不是模板。每题：

```
### Q：问题
**一句话答**：……（能脱口而出的）
**展开**：……（2-4 句，体现工程深度）
**加分项 / 反例**：……（说出这个面试官会高看一眼）
```

demo：做一个 `quiz.py`，命令行随机抽题自测；或一个把概念跑给你看的 mini 示例（例如「ReAct 到底长什么样」直接打印一个 trace）。
