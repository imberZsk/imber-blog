# 05 Python 基础语法 demo

用最小的 Python 语法（变量、条件、循环、函数、字符串格式化）写一个知识库问答脚本骨架，让你看到写 AI 应用脚本前期不需要复杂语法。

## 运行

```bash
python3 main.py
```

零依赖，纯标准库。

## 预期输出

```
问：报销流程是什么？
答：根据资料，报销需在产生费用后 30 天内提交，附发票和审批单。
----------------------------------------
问：怎么请假？
答：根据资料，请假需提前 1 天在系统提交，主管审批后生效。
----------------------------------------
问：公司班车几点发车？
答：知识库里没有相关资料，请换个问法或补充文档。
----------------------------------------
问：(空输入)
答：请输入一个问题。
----------------------------------------
```

## 代码对应文章的哪些点

| 语法点 | 在 main.py 哪里 |
|---|---|
| 函数定义 + 类型标注 | `build_prompt`、`answer`、`fake_model` |
| 条件分支处理失败路径 | `answer` 里的空输入判断、未命中判断 |
| 循环遍历检索 | `answer` 里 `for keyword, chunks in knowledge.items()` |
| 字符串格式化（三引号 + f-string） | `build_prompt` 里拼提示词 |
| dict / list 数据结构 | `knowledge` 知识库、`hits` 命中列表 |
