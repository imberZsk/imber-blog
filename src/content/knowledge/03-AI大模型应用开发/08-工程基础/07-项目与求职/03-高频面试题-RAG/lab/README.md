# 49 高频面试题 RAG —— 抽题自测

从 11 道 RAG 高频真题里随机抽题自测：先显示问题，回车后再看参考答案，模拟面试"先自己答、再对答案"的节奏。题库内容和 49 篇正文一致。

## 运行

```bash
python3 quiz.py
```

零依赖，纯标准库。

## 三种用法

```bash
python3 quiz.py          # 随机抽 5 题，逐题自测（回车看答案，Ctrl+C 退出）
python3 quiz.py -n 3     # 随机抽 3 题
python3 quiz.py --all    # 通读全部 11 题和答案，不交互
```

## 预期输出（抽题模式）

```
RAG 面试自测：本次随机抽了 5 题，共 11 题题库。

第 1/5 题
Q：chunk 切太大或太小分别有什么问题？
（想好后按回车看参考答案，Ctrl+C 退出）
  一句话答：太大答案被无关内容淹没、还浪费上下文；太小语义被切断、检索命中但信息不全。
  展开：...
  加分项：...
```

## 怎么用它准备面试

- 第一遍 `--all` 通读，把每题的"一句话答"先记住，做到张口就来。
- 之后每天 `python3 quiz.py` 抽 5 题，蒙上答案自己讲一遍，再回车对照。
- 卡壳的题回 49 篇正文重点看，把"展开"和"加分项"也能自然说出来。

## 动手改

- 往 `QUESTIONS` 里加你面试真碰到的题，把题库变成你自己的。
- 把答错的题做个标记，下次优先抽。
