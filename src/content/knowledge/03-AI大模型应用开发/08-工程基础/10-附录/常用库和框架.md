# 附录：常用库和框架

> 目标：知道 AI 应用开发常见工具分别负责什么，避免一开始就被生态名词淹没。

## 后端与接口

- FastAPI：Python Web 框架，适合写 AI 后端接口。
- Uvicorn：FastAPI 常用开发服务器。
- Pydantic：请求、响应和配置的数据模型校验。
- httpx / requests：调用外部 HTTP API。

## LLM 应用

- OpenAI 兼容 SDK：调用云端或本地兼容模型接口。
- LangChain：封装 Prompt、Retriever、Tool、Chain 等组件。
- LangGraph：用图和状态管理复杂 Agent / Workflow。
- Dify / Coze：低代码搭建聊天、知识库、插件和工作流。

## RAG

- Chroma：适合本地和轻量知识库。
- Milvus：适合更大规模向量检索。
- pgvector：PostgreSQL 的向量扩展，适合已有 PG 技术栈。
- Elasticsearch：适合关键词检索和混合检索。

## 进阶 RAG 与评测

- OpenSearch / Elasticsearch：关键词检索、BM25、混合检索。
- Neo4j：知识图谱和多跳关系查询。
- MinIO：保存原文、图片、表格截图等证据资产。
- RAGAS：RAG 自动化评测指标工具。
- LangFuse：Prompt、Trace、评测和观测平台。

## 多模态与部署

- OCR：把扫描件或图片里的文字提取出来。
- VLM：理解图片、图表、截图内容。
- ASR / TTS：语音客服链路里的语音识别和语音合成。
- vLLM：自部署大模型推理服务，常用于高并发和 Prefix Cache。
- MCP：把工具、资源和 Prompt 以协议方式暴露给 Agent。

## 测试与工程化

- pytest：Python 测试。
- Playwright：端到端测试和前端交互验证。
- Docker：容器化部署。
- Redis：缓存、限流、任务状态。

## 选型建议

学习阶段先手写最小实现，知道每个环节在做什么；项目阶段再按需求引入框架。框架是加速器，不是理解的替代品。
