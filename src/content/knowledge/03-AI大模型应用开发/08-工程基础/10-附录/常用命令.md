# 附录：常用命令

> 目标：保留验证 Python、Node.js、HTTP 服务和 Git 变更时最常用的通用命令，不绑定某个本地绝对路径。

## Node.js 项目

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm test
pnpm build
```

## Python 虚拟环境

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest
```

## 常见本地服务检查

```bash
curl --fail-with-body http://localhost:8000/health
curl --fail-with-body -X POST http://localhost:8000/api/chat \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <test-token>' \
  -d '{"message":"报销流程是什么？","session_id":"local-test"}'
```

## Git 检查

```bash
git status --short
git diff --stat
```

## 如何判断命令是否成功

- 安装命令必须以退出码 `0` 结束，不能只看最后一行没有红字。
- Lint、类型检查和测试要分别执行；其中一项通过不能证明其他检查也通过。
- 健康检查不仅确认端口可连接，还要校验 HTTP 状态码和必要响应字段。
- 修改代码后先看 `git status --short` 确认文件范围，再用 `git diff --check` 排除空白错误。

## 常见失败怎么查

依赖安装失败时先核对 Node.js 或 Python 版本、锁文件和包源；服务访问失败时依次检查进程、监听端口、健康接口和环境变量。测试偶发失败时保留失败日志、随机种子和输入数据，不要直接循环重跑掩盖问题。

## 学习建议

每个项目 README 至少写清安装、配置、启动、测试和健康检查。命令中的端口与接口必须和当前项目一致，不能直接复制本文占位值。
