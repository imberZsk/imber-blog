# 附录：常用命令

> 目标：保留验证 Python、Node.js、HTTP 服务和 Git 变更时最常用的通用命令，不绑定某个本地绝对路径。

## Node.js 项目

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm test
pnpm build
```

## Python 虚拟环境

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest
```

## 常见本地服务检查

```bash
curl --fail-with-body http://localhost:8000/health
curl --fail-with-body -X POST http://localhost:8000/api/chat \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <test-token>' \
  -d '{"message":"报销流程是什么？","session_id":"local-test"}'
```

## Git 检查

```bash
git status --short
git diff --stat
```

## 学习建议

每个项目 README 至少写清安装、配置、启动、测试和健康检查。命令中的端口与接口必须和当前项目一致，不能直接复制本文占位值。
