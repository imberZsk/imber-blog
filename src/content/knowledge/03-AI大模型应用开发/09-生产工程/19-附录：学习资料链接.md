# 生产工程（19） - 附录：学习资料链接

> 目标：给后续补资料留一个清单位置，避免资料散在聊天记录里。

## 官方文档优先

- Python 官方文档：语法、标准库、venv。
- FastAPI 官方文档：接口、请求响应模型、流式响应。
- OpenAI / 模型服务商官方文档：API、模型、工具调用、结构化输出。
- LangChain / LangGraph 官方文档：框架概念、组件和示例。
- Dify / Coze 官方文档：平台能力、知识库、工作流、插件。

## 学习资料筛选标准

- 是否有可运行代码。
- 是否解释工程边界，而不是只展示效果。
- 是否包含错误处理、日志、测试和部署。
- 是否能对应到你的主项目。

## 推荐记录方式

每看完一个资料，沉淀四行：

1. 它解决什么问题？
2. 我能放进哪个项目？
3. 有什么坑？
4. 下一步要写哪段代码？
