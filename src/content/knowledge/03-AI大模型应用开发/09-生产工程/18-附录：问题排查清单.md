# 生产工程（18） - 附录：问题排查清单

> 目标：遇到 AI 应用问题时按顺序排查，不靠猜。

## 模型不回答或回答很慢

- 检查 API Key、模型名、网络和超时配置。
- 检查输入是否过长，是否超过上下文窗口。
- 检查后端是否有重试和降级。
- 检查前端是否正确处理 loading 和 error。

## RAG 回答不准

- 问题是否命中了相关 chunk？
- chunk 是否太小或太大？
- metadata 是否丢失？
- topK 是否合理？
- Prompt 是否要求基于资料回答？
- 是否需要关键词检索或 rerank？

## Agent 工具调用错

- 工具描述是否清楚？
- 参数 schema 是否严格？
- 后端是否做白名单和权限校验？
- 是否设置最大步数？
- trace 是否记录了调用原因和结果？

## JSON 解析失败

- Prompt 是否明确输出格式？
- 是否使用 schema 或解析校验？
- 是否保留 raw 输出？
- 是否有重试或修复逻辑？

## 交付前检查

- README 有启动和测试命令。
- demo 无 API Key 也能跑基础流程。
- 至少有一组自动化测试。
- 前端能展示回答、引用、工具过程和错误。
- 文章能对应到 demo 代码。
