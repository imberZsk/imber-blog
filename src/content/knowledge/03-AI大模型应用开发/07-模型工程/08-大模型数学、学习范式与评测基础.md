# 模型工程（08） - 大模型数学、学习范式与评测基础

> 应用工程师不必从零推导所有公式，但必须理解向量、概率、梯度和泛化，否则很难判断 Embedding、采样、微调与评测结果。

> 读完你能：用最低必要数学解释模型训练和推理，并识别数据泄漏、过拟合和错误指标。

## 核心知识清单

- 向量、矩阵、点积与线性变换
- 概率分布、Logits、Softmax 与交叉熵
- 导数、梯度、反向传播与优化器
- 监督学习、无监督学习与自监督语言建模
- 训练集、验证集、测试集与数据泄漏
- 过拟合、泛化、Precision、Recall 与 F1
- CNN、RNN、Transformer 与序列任务边界

## 最低必要数学

Embedding 是向量，模型权重通常表示为矩阵；点积衡量方向一致程度，也是注意力和相似度计算的重要基础。Logits 是未归一化分数，Softmax 将其转换为概率分布；交叉熵惩罚目标 Token 概率过低。

梯度表示参数变化对损失的影响，反向传播按计算图把梯度传回各层，优化器据此更新权重。学习率过大可能发散，过小则训练缓慢；训练 Loss 下降只证明拟合训练数据，不证明业务泛化。

## 学习范式

监督学习使用标签学习输入到输出，例如意图分类；无监督学习发现无标签结构，例如对 Embedding 聚类；大语言模型预训练通常采用自监督的下一个 Token 预测，从原始文本自动构造目标。SFT 再用指令答案对调整行为，偏好优化学习候选答案的相对偏好。

CNN 擅长局部空间特征，RNN 顺序维护隐藏状态，Transformer 用注意力并行建模远距离依赖。理解历史架构有助于判断视觉、语音和序列任务，但应用选型仍应以实际 Dataset 为准。

## 数据与指标

训练、验证和测试必须按用户、时间或来源合理分组；同一文档的近重复 Chunk 不能同时进入训练和测试。过拟合常表现为训练指标持续改善、验证指标停滞或下降。

分类任务中 Precision 关注“预测为正的有多少正确”，Recall 关注“真实为正的有多少找回”，F1 是两者调和平均。类别不平衡时不能只看 Accuracy；RAG、生成和 Agent 还需要各自的检索、忠实度与任务成功指标。
