# Mem0 记忆生命周期交互 Demo

这个浏览器实验用确定性规则模拟 Mem0 的关键生命周期，而不是把聊天记录原样保存。点击“下一轮对话”可依次看到 `ADD → UPDATE → NOOP → DELETE`，再用检索框观察精确属性、语义关键词和新鲜度三路得分。

## 页面运行

在文章中的实验区点击“运行”，然后逐轮执行。HTML 沙盒不联网、不读取站点 Cookie，也不需要 API Key。

## 本地查看

直接用浏览器打开 `sandbox.html` 即可。

## 与真实 Mem0 的边界

- 真实 Mem0 通常用 LLM 抽取候选记忆，并使用 Embedding、向量库或图存储完成检索。
- 本实验用可读规则代替 LLM 和 Embedding，只为了让写入决策、冲突覆盖、删除和召回排序可复现。
- 生产环境仍需租户隔离、敏感信息过滤、审计、删除传播和 API 契约测试。
