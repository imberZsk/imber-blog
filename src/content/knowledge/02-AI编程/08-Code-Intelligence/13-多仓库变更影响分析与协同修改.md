# 四、最小实践：从 AST 提取函数符号

下面脚本只依赖 Python 3.10+ 标准库，
执行 `python symbols.py target.py`，
输出函数名称和起始行。

```python
import ast
from pathlib import Path
import sys


def list_functions(source_file: Path) -> list[tuple[str, int]]:
    """解析 Python 文件并返回函数符号；source_file 是待分析源码。"""
    # 保存源码解析得到的抽象语法树。
    syntax_tree = ast.parse(source_file.read_text(encoding="utf8"), filename=str(source_file))
    return [
        (node.name, node.lineno)
        for node in ast.walk(syntax_tree)
        if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef))
    ]


# 保存命令行指定的源码路径。
target_file = Path(sys.argv[1])
for symbol_name, line_number in list_functions(target_file):
    print(f"{symbol_name}:{line_number}")
```

这个示例能证明 AST 比正则更懂语法，但它还没有跨文件类型、引用和调用关系；
那些能力需要 LSP、符号表或专门索引。
