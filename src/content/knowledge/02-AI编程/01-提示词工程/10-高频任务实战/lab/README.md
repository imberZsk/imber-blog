# 09-demo：四类高频任务的「拿来即用」模板

这个 Demo 不用写代码、不用装东西。下面是写作、总结、翻译、数据提取四类任务各一个模板。
**用法：复制对应模板 → 把 `{}` 里的内容换成你的 → 粘进任意 AI 工具（ChatGPT / Claude / 文心 / 通义 / Kimi 等）。**

---

## 模板 1：写作

```
你是一位{身份，例如：资深市场文案}。

请帮我写一篇{文体，例如：产品上新公众号推文}。

【背景信息】
- 主题：{写什么}
- 目标读者：{给谁看}
- 我想达到的效果：{让读者看完做什么}

【写作要求】
- 语气风格：{例如：轻松、专业、有网感}
- 篇幅：{例如：不超过 300 字}
- 必须包含：{关键卖点 / 关键信息}
- 不要出现：{禁忌词 / 不想要的风格}

【输出格式】
- {例如：直接给正文；或：先给 3 个标题备选，再给正文}
```

踩坑提醒：别只说「写专业点」，把「专业」拆成可执行的要求（短句、第一人称、每段不超过 3 行）。

---

## 模板 2：总结

```
请帮我总结下面这段内容。

【总结要求】
- 用途：{例如：给没看过原文的领导快速了解}
- 视角：{例如：只关注和「成本」相关的信息}
- 长度：{例如：3 到 5 条要点，每条一句话}
- 取舍：{例如：忽略寒暄和铺垫，只保留结论和数据}

【输出格式】
- 用无序列表，每条以「• 」开头
- 末尾单独给一句「一句话总结」

【待总结内容】
"""
{把原文粘到这里}
"""
```

踩坑提醒：一定要限定长度，否则「越总结越长」；原文太长会超上下文窗口，先分段总结再合并。

---

## 模板 3：翻译

```
请把下面的中文翻译成英文。

【翻译要求】
- 场景：{例如：正式商务邮件 / 产品 UI 文案 / 朋友间聊天}
- 风格：{例如：自然地道，像母语者写的，不要逐字直译}
- 术语：{例如：「会员」统一翻成 "membership"，不要用 "VIP"}
- 保留：{例如：保留原文的分段和 Markdown 格式}

【输出格式】
- 只输出译文，不要解释
- 如果某句有多种译法，在译文下方用「备选：」补充

【原文】
"""
{粘贴原文}
"""
```

踩坑提醒：场景决定语气，一定要给；专有名词提前用术语表锁死，避免一会儿 user 一会儿 customer。

---

## 模板 4：数据提取

```
请从下面的文本中提取信息，按指定 JSON 格式输出。

【要提取的字段】
- name：姓名（找不到填 null）
- phone：手机号（找不到填 null）
- intent：咨询意图，只能是 ["购买", "售后", "投诉", "其他"] 之一

【输出要求】
- 严格输出 JSON，不要任何额外文字、不要 Markdown 代码块包裹
- 字段缺失一律填 null，不要瞎编

【示例】
输入：你好，我叫李雷，想问下你们的会员怎么续费，我电话 13800001111
输出：{"name": "李雷", "phone": "13800001111", "intent": "购买"}

【待提取文本】
"""
{粘贴文本}
"""
```

踩坑提醒：必须写明「找不到填 null」，否则模型会编；枚举值要写死可选范围，否则分类发散；给一个示例胜过十句描述。

---

## 一个共同的骨架

这四个模板都在重复同一套结构：**身份/场景 + 要求/约束 + 示例 + 输出格式 + 用 `"""` 隔离素材**。
记住这套骨架，遇到新任务照着填空就行，不用每次从零写。
