# 03-demo：提示词演进对照清单（v1 烂 → v4 好）

这个 Demo 不用写代码，也不用装东西。它把小册 03 章的核心——**好提示词是一层层「加料」搭出来的**——做成一份可以亲手验证的清单。

## 怎么用

1. 打开任意一个 AI 对话工具（ChatGPT、Claude、文心、通义、Kimi 都行）。
2. 拿下面任意一个案例，**从 v1 到 v4 挨个复制进去**，看每一版结果。
3. 留意每升一级，加了什么、结果好在哪。
4. 最后照着「加料公式」，把你自己手头的需求也升一遍级。

---

## 案例 A：写一条咖啡店开业朋友圈

### v1 随手一问（差）
```
帮我写条朋友圈宣传咖啡店
```
结果：万能模板文案，换谁都能用，等于谁都打动不了。

### v2 加「清晰具体」（及格）
```
帮我写一条朋友圈，宣传我新开的咖啡店，主打手冲咖啡，
环境安静适合办公，希望吸引附近的上班族来。
```
加了：卖点 + 目标人群。结果开始「像那么回事」。

### v3 加「上下文 + 期望输出」（良好）
```
背景：我在科技园区新开了一家咖啡店，叫「慢格 Slow Lab」，
主打精品手冲，店里安静、有大桌和插座，适合一个人办公或小聚。
周边都是程序员和创业公司。

请帮我写一条发在朋友圈的开业宣传文案。
要求：
- 语气轻松、有点文艺，但不要太矫情
- 100 字以内
- 结尾给一个让人想来的理由或小福利钩子
- 配 3 个相关话题标签（#xxx）
```
加了：完整背景 + 输出要求（语气/字数/钩子/标签）。结果已能直接发。

### v4 加「示例 + 约束」打磨（优秀）
```
背景：我在科技园区新开了一家咖啡店，叫「慢格 Slow Lab」，
主打精品手冲，店里安静、有大桌和插座，适合一个人办公或小聚。
周边都是程序员和创业公司。

请帮我写一条发在朋友圈的开业宣传文案。

要求：
- 语气轻松、有点文艺，但不要太矫情，别用「全城最」这类夸张词
- 100 字以内
- 开头第一句要能抓住「天天对着电脑的打工人」
- 结尾给一个开业福利钩子（比如「前 3 天手冲第二杯半价」）
- 配 3 个相关话题标签

风格参考（这种调性，不要照抄内容）：
「在格子间待久了，连呼吸都想换个地方。」

请直接给文案，不要额外解释。
```
加了：更细的约束 + 一个风格示例 + 明确边界。结果稳定、有个性、合你审美。

## 案例 B：给一份数据做分析

### v1（差）
```
帮我分析一下这个数据
（粘贴数据）
```
没说分析什么、给谁看、要什么结论——只能瞎答。

### v2（及格）
```
这是我们公司上半年的月度销售额数据，帮我分析整体趋势和异常月份。
（粘贴数据）
```
加了：明确分析方向（趋势 + 异常）。

### v3（良好）
```
这是我们公司上半年的月度销售额数据。
请帮我分析：
1. 整体趋势是上升还是下降
2. 哪个月波动最大，并推测可能原因
3. 用一句话给出对下半年的建议
用分点形式输出，每点不超过两句话。
（粘贴数据）
```
加了：拆成 3 个具体角度 + 输出格式 + 长度。

### v4（优秀）
```
你是一名资深业务分析师。
这是我们公司上半年的月度销售额数据。

请分析：
1. 整体趋势（上升/下降/持平）
2. 波动最大的月份及可能原因
3. 一句话的下半年建议

要求：
- 用分点形式，每点不超过两句话
- 只基于我给的数据，不要编造没有的信息；数据不足以判断的地方直接说「数据不足」
- 不要复述原始数据，直接给结论

数据如下：
（粘贴数据）
```
加了：角色 + 防幻觉约束（只基于给定数据 / 不足就说不足）+ 去冗余约束。

## 加料公式（背下来）

> **v1 一句话 → +清晰具体 → +上下文和输出要求 → +示例和约束 → 好提示词。**

每往上加一层，结果就更可用一截。好提示词不是「想出来」的，是**搭出来**的。

## 动手练习

挑一件你这周真要做的事，先写出你的 v1，再按公式一步步升到 v4，把四个版本都丢给 AI 跑一遍，亲眼对比差距。这是练提示词最快的方法。
