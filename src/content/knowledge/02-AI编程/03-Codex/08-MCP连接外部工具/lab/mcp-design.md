# MCP 工具设计清单

## 工具名

`search_personal_docs`

## 用途

查询个人学习目录里的 Markdown 笔记。

## 输入

- `query`：搜索关键词。
- `limit`：最多返回多少条，默认 5。

## 输出

- `title`：笔记标题。
- `path`：本地路径。
- `snippet`：命中的短摘要。

## 权限

- 只读。
- 只能访问学习目录。
- 不读取 `.env`、密钥文件、浏览器数据。

## 审计

- 记录查询关键词。
- 记录返回文件路径。
- 不记录文件全文。

## 后续扩展

- 支持按主题过滤。
- 支持读取某篇笔记全文。
- 写操作单独设计，不和搜索工具混在一起。
