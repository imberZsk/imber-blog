# 一、好提示词，先从三条原则开始

上一章我们搞懂了模型怎么「想」：它看不到你脑子里的东西，只能根据你给的文字接龙，还会脑补。所以写好提示词，本质就是**把它需要的东西一次说清楚，少让它猜**。

这件事听起来玄，其实就抓三条原则：

1. **清晰具体**——别让它猜你要什么。
2. **给足上下文**——告诉它「为了什么、给谁、在什么背景下」。
3. **明确期望输出**——说清你要的结果长什么样。

这一章，我们一条一条讲，最后用一个完整的例子，把这三条揉在一起，看一个提示词怎么从「烂」一步步变「好」。

---

# 二、原则一：清晰具体——别让模型猜

## 2.1 模糊指令的问题

看这两个提示词的区别：

```text
❌ 帮我分析一下这个数据
```

模型懵了：分析什么？从什么角度？要多深？给谁看？它只能挑一个最「像样」的方向瞎答，多半不是你要的。

```text
✅ 这是我们公司上半年的月度销售额数据。
请帮我分析：
1. 整体趋势是上升还是下降
2. 哪个月波动最大，可能的原因
3. 用一句话给出对下半年的建议
```

同样一件事，第二个把「分析什么、几个角度、要什么结论」全说清了，模型立刻知道该干嘛。

## 2.2 清晰具体的几个抓手

把模糊的动词换成具体的要求，常用这几招：

- **把「好一点」换成可量化的标准。** 「写短一点」→「不超过 100 字」；「专业一点」→「用面向工程师的术语」。
- **把「分析/处理/优化」这类大词拆成具体动作。** 「优化这段代码」→「减少重复代码，并给每个函数加注释」。
- **限定范围和角度。** 「介绍一下 Python」→「面向零基础新手，介绍 Python 适合做什么、不适合做什么」。

> 一句话：**凡是你心里有标准的地方，都把标准写出来。** 你不写，它就替你定，而它定的多半不合你意。

# 三、原则二：给足上下文——它不了解你

模型不知道你是谁、在做什么、给谁看、之前发生过什么。这些**背景信息**就是上下文。给足了，它才能答到点子上。

对比一下：

```text
❌ 帮我写一段产品介绍
```

```text
✅ 背景：我们是一款面向小学生的英语单词 App，主打「每天 5 分钟、游戏化记单词」。
现在要在应用商店写一段介绍。
目标用户：给孩子选 App 的家长。
请写一段产品介绍，突出「省时间」和「孩子愿意主动学」这两个卖点。
```

第二个交代了：**我是谁（什么产品）、给谁看（家长）、要突出什么（两个卖点）、用在哪（应用商店）**。模型有了这些，写出来的东西才贴合你的真实场景，而不是一段放之四海而皆准的废话。

## 3.1 哪些上下文值得给

不用全给，但下面这些一旦相关，就别省：

- **你是谁 / 做什么的**：行业、产品、身份。
- **给谁看**：受众是专家还是小白？是客户还是同事？
- **用在什么场景**：发朋友圈、写进报告、还是内部讨论？
- **相关的事实和材料**：要总结的原文、要参考的数据、要遵守的规范。
- **已有的尝试**：「我试过这么写但太啰嗦了」——告诉它你不要什么，也是上下文。

---

# 四、原则三：明确期望输出——告诉它结果长什么样

很多人交代了任务，却忘了说「我要的结果长什么样」。结果模型给你一大段散文，你却想要个表格；或者它给你三段，你只想要三句话。

把输出的**形式、长度、结构**说清楚：

```text
❌ 给我几个起名方案
```

```text
✅ 帮我给一款「主打助眠的白噪音 App」起名。
要求：
- 给 5 个候选名
- 每个名字配一句话说明寓意
- 风格偏温柔、治愈，避免生硬的科技感
- 用表格输出，两列：名字 | 寓意
```

第二个明确了**数量（5 个）、附加信息（寓意）、风格（温柔治愈）、格式（表格两列）**。拿到的结果直接能用，不用你再返工。

## 4.1 常用的「输出要求」清单

- **格式**：列表？表格？JSON？分段？纯文本？
- **长度**：多少字 / 几条 / 几段。
- **结构**：要不要小标题、要不要先给结论再展开。
- **语气**：正式 / 口语 / 幽默 / 严肃。
- **要 / 不要什么**：「不要寒暄」「不要用专业术语」「末尾加一句总结」。

# 五、实战：从「一句话需求」演进到「好提示词」

光讲原则太抽象。我们拿一个真实需求，从最烂的版本开始，一版版加料，你能清楚看到每一步加了什么、为什么变好。

**需求**：我想让 AI 帮我写一条朋友圈，宣传我新开的咖啡店。

## 5.1 v1：随手一问（差）

```text
帮我写条朋友圈宣传咖啡店
```

**问题**：太笼统。什么咖啡店？开在哪？有什么特色？给谁看？模型只能编一条「正确但毫无个性」的万能文案，换成任何一家店都能用，也就等于谁都打动不了。

## 5.2 v2：加上「清晰具体」（及格）

```text
帮我写一条朋友圈，宣传我新开的咖啡店，主打手冲咖啡，
环境安静适合办公，希望吸引附近的上班族来。
```

**加了什么**：明确了卖点（手冲、安静、适合办公）和目标人群（附近上班族）。

**进步**：模型知道方向了，写出来的内容开始「像那么回事」。**还差什么**：没说语气、长度、格式，结果可能过长、过于官方、或者没有行动号召。

## 5.3 v3：补上「上下文 + 期望输出」（良好）

```text
背景：我在科技园区新开了一家咖啡店，叫「慢格 Slow Lab」，
主打精品手冲，店里安静、有大桌和插座，适合一个人办公或小聚。
周边都是程序员和创业公司。

请帮我写一条发在朋友圈的开业宣传文案。
要求：
- 语气轻松、有点文艺，但不要太矫情
- 100 字以内
- 结尾给一个让人想来的理由或小福利钩子
- 配 3 个相关的话题标签（#xxx）
```

**加了什么**：完整背景（店名、位置、特色、周边人群）+ 输出要求（语气、字数、要有钩子、要话题标签）。

**进步**：这条提示词已经能拿到一条**像样、能直接发**的文案了。

## 5.4 v4：再加「示例 + 约束」打磨（优秀）

```text
背景：我在科技园区新开了一家咖啡店，叫「慢格 Slow Lab」，
主打精品手冲，店里安静、有大桌和插座，适合一个人办公或小聚。
周边都是程序员和创业公司。

请帮我写一条发在朋友圈的开业宣传文案。

要求：
- 语气轻松、有点文艺，但不要太矫情，别用「全城最」这类夸张词
- 100 字以内
- 开头第一句要能抓住「天天对着电脑的打工人」
- 结尾给一个开业福利钩子（比如「前 3 天手冲第二杯半价」）
- 配 3 个相关话题标签

风格参考（这种调性，不要照抄内容）：
「在格子间待久了，连呼吸都想换个地方。」

请直接给文案，不要额外解释。
```

**加了什么**：
- **更细的约束**：禁用夸张词、规定开头要抓的人群、福利给了具体例子。
- **一个风格示例**：用一句话告诉它「我要的调性长这样」——这比形容词「文艺」精准一百倍。
- **明确边界**：「直接给文案，不要额外解释」，省得它前面铺垫一堆。

**结果**：到这一版，你基本能稳定拿到一条**有个性、能直接用、符合你审美**的文案。

## 5.5 把演进过程提炼成一句话

> **v1 一句话 → v2 加清晰具体 → v3 加上下文和输出要求 → v4 加示例和约束打磨。**
> 你会发现：好提示词不是「想出来」的，是**一层层加料「搭」出来**的。

---

# 六、常见错误（新手最容易踩的坑）

1. **用模糊的大词。** 「优化一下」「专业一点」「好看点」——这些词你自己都没标准，模型更没有。
2. **忘了交代背景。** 直接抛任务，不说自己是谁、给谁看，结果只能是「通用废话」。
3. **不说要什么格式和长度。** 然后嫌它「答得太长」「不该用表格」——其实是你没说。
4. **想一次到位。** 期待 v1 就拿到 v4 的效果。好提示词是调出来的，先写具体，再看结果补料。
5. **只说「不要什么」却不说「要什么」。** 「别太正式」之后呢？最好同时给出正面方向，比如「像跟朋友聊天那样」。

---

# 七、最佳实践（可落地的心法）

- **写之前先问自己三件事**：我到底要什么（清晰具体）？它需要知道什么背景（上下文）？我要的结果长什么样（期望输出）？
- **能给例子就给例子。** 一句「我要这种调性」的示例，胜过十个形容词。
- **先具体写一版，再看结果补料。** 把它当成迭代，不是一次成。
- **凡是你心里有标准的地方，都写出来。** 长度、格式、语气、禁忌，全交代清楚。
- **最后加一句「直接给结果，不要解释」**，能省掉大量无用铺垫（需要它解释时另说）。

---

# 八、本章小结

- 三条最基本的原则：**清晰具体、给足上下文、明确期望输出**。
- 清晰具体 = 别让它猜，把心里的标准写出来。
- 给足上下文 = 它不了解你，背景、受众、场景、材料该给就给。
- 明确期望输出 = 说清结果的格式、长度、结构、语气。
- 好提示词是**一层层加料搭出来的**，不是一句话碰运气。

掌握了这三条，你已经能写出比 90% 的人都好的提示词了。下一章，我们把这些零散的原则升级成一个**可复用的骨架**——五要素框架，让你以后写任何专业提示词都有章可循。

## 10.3 案例 B：给一份数据做分析

### v1（差）
```text
帮我分析一下这个数据
（粘贴数据）
```
没说分析什么、给谁看、要什么结论——只能瞎答。

### v2（及格）
```text
这是我们公司上半年的月度销售额数据，帮我分析整体趋势和异常月份。
（粘贴数据）
```
加了：明确分析方向（趋势 + 异常）。

### v3（良好）
```text
这是我们公司上半年的月度销售额数据。
请帮我分析：
1. 整体趋势是上升还是下降
2. 哪个月波动最大，并推测可能原因
3. 用一句话给出对下半年的建议
用分点形式输出，每点不超过两句话。
（粘贴数据）
```
加了：拆成 3 个具体角度 + 输出格式 + 长度。

### v4（优秀）
```text
你是一名资深业务分析师。
这是我们公司上半年的月度销售额数据。

请分析：
1. 整体趋势（上升/下降/持平）
2. 波动最大的月份及可能原因
3. 一句话的下半年建议

要求：
- 用分点形式，每点不超过两句话
- 只基于我给的数据，不要编造没有的信息；数据不足以判断的地方直接说「数据不足」
- 不要复述原始数据，直接给结论

数据如下：
（粘贴数据）
```
加了：角色 + 防幻觉约束（只基于给定数据 / 不足就说不足）+ 去冗余约束。

## 10.4 加料公式（背下来）

> **v1 一句话 → +清晰具体 → +上下文和输出要求 → +示例和约束 → 好提示词。**

每往上加一层，结果就更可用一截。好提示词不是「想出来」的，是**搭出来**的。

## 10.5 动手练习

挑一件你这周真要做的事，先写出你的 v1，再按公式一步步升到 v4，把四个版本都丢给 AI 跑一遍，亲眼对比差距。这是练提示词最快的方法。
