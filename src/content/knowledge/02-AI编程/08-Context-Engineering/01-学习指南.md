# Context Engineering（01） - 学习指南

> Context Engineering 的目标是让 Agent 在每一步看到正确、足量、最新且权限合适的信息，而不是把整个仓库塞进上下文窗口。

## 学习目标

- 上下文分层、预算与压缩
- 仓库检索、Repo Map 与 Code RAG
- Memory、规则文件与知识保鲜

## 推荐顺序

1. 先建立常驻、任务、按需和运行反馈四层上下文。
2. 再学习符号、调用链和代码检索，减少无差别读取。
3. 最后设计长期记忆的写入、失效和安全边界。

## 学完验收

- 能为真实任务列出必须提供、按需读取和禁止进入上下文的信息。
- 能从一个接口追到定义、调用方、数据模型和测试。
- 能解释规则文件、Memory 和 Skill 的区别及更新时机。
