# 二、主题拆解：语义记忆、情景记忆与程序性记忆的关键机制

- **语义记忆、情景记忆与程序性记忆**：记忆记录包含 namespace、subject、fact、source、version、confidence、created_at 和 expires_at。
- **语义记忆、情景记忆与程序性记忆**：写入前提取候选事实并去重，读取时按权限、相关性、新鲜度和置信度排序。
- **语义记忆、情景记忆与程序性记忆**：冲突不直接覆盖：保留两个版本、证据和仲裁结果；删除请求要传播到缓存与索引。

# 三、核心机制：输入、状态、输出和失败


- **语义记忆、情景记忆与程序性记忆判断 1**：状态要区分可重建上下文、必须持久化的业务事实和只用于调试的轨迹，不能把整段对话当数据库。
- **语义记忆、情景记忆与程序性记忆判断 2**：Checkpoint 必须带版本、幂等键和输入摘要，恢复前要验证代码、工具和权限是否仍兼容。
- **语义记忆、情景记忆与程序性记忆判断 3**：删除、过期和冲突合并是状态模型的一部分；只有写入没有治理的记忆会持续污染后续任务。

# 四、最小实践：带命名空间和 TTL 的记忆


```python
from dataclasses import dataclass
from time import time


@dataclass(frozen=True)
class MemoryRecord:
    """保存隔离命名空间、事实、来源和过期时间。"""

    namespace: str  # 保存用户、仓库和任务组合出的隔离键。
    fact: str  # 保存经过提取和审核的事实。
    source: str  # 保存事实可回链的来源。
    expires_at: float  # 保存记录过期的 Unix 时间。


def recall(records: list[MemoryRecord], namespace: str) -> list[MemoryRecord]:
    """返回指定命名空间内尚未过期的记忆。"""
    # 保存召回发生时的当前时间。
    current_time = time()
    return [record for record in records if record.namespace == namespace and record.expires_at > current_time]
```
