# 《Claude Code》学习小册 · 学习路线与目录

> 一份从零基础到能让 Claude Code「并行干活、远程干活、自己干活」的渐进式学习地图。
> 每一章都标注「学习目标」和「学完你能做什么」，照着走不会迷路。

---

## 🗺️ 整体路线一览

全书分五篇，像通关一样一层一层往上打：

```
入门篇(01-04)      进阶篇(05-10)        规模化篇(11-14)        自主运行篇(15-18)      远程无头篇(19-21)+实战(22)
跑起来        →    用透单兵能力     →   多代理并行        →    让它自己循环跑     →   脱离终端 / 真实交付
「敢用」            「会用」              「并行用」             「放手用」             「随处用 + 用得好」
```

- **入门篇**：装好、跑通、看懂它一步步怎么干活，外加「后悔药」检查点回溯。
- **进阶篇**：单兵能力用透——配置、权限、搜索改码、测试文档、Git、自定义命令。
- **规模化篇**：从「一个代理」到「一支队伍」——子代理、Agent Team、Worktrees、车队监控。
- **自主运行篇**：让它脱离你的逐句指挥——循环、目标导向、后台监控、流程固化。
- **远程无头篇 + 实战**：手机/网页/CI 里都能用，最后在真实项目里跑完整闭环。

> 📎 已有两篇专题笔记（《常用工作流.md》《最佳实践.md》）的干货，会被吸收进对应章节，不重复造轮子。

## 📚 详细章节

### 入门篇 · 先把它跑起来

#### 01 · 认识 Claude Code：它到底是什么
- **目标**：搞清它是什么、和 ChatGPT/Copilot 的本质区别、适合哪类任务。
- **学完你能**：一句话讲清它，并判断手头任务适不适合交给它。

#### 02 · 安装与第一次对话
- **目标**：完成安装、登录认证，跑通第一次对话。
- **学完你能**：在自己电脑上启动它，让它读懂项目并回答第一个问题。

#### 03 · 基础交互：怎么问它才听得懂
- **目标**：掌握下达指令的姿势——描述任务、用 `@` 引用文件/目录、贴图、让它分步走。
- **学完你能**：写出清晰指令，让它准确完成一个小改动。

#### 04 · 工作循环与检查点回溯：读—改—跑—验证 + 后悔药
- **目标**：理解它的核心工作循环；学会用检查点（`Esc Esc`）把文件回退到任意一步。
- **学完你能**：看懂它每步在做什么，改错了能一键回溯，放心大胆地试。

---

### 进阶篇 · 把单兵能力用透

#### 05 · CLAUDE.md 与记忆分级：给项目立规矩
- **目标**：用 `CLAUDE.md` 沉淀约定，理解项目级/用户级/本地级记忆分级，把规则写成「可检查、可执行」。
- **学完你能**：写一份高质量 `CLAUDE.md`，让它每次都按你的规矩办事。

#### 06 · 权限模式与 Plan Mode：安全地放手
- **目标**：理解权限模式（询问/接受编辑/计划/bypass），用 Plan Mode 先规划后执行。
- **学完你能**：按任务风险选模式，复杂任务先出计划再动手。

#### 07 · 核心工作流：理解代码库 / 查找代码 / 修 Bug
- **目标**：快速获取代码库概览、定位相关代码、复现并修复 Bug。
- **学完你能**：独立走完「读懂→定位→修复→验证」闭环。

#### 08 · 写测试与处理文档：参与完整开发闭环
- **目标**：让它补测试、跑测试、生成与校对文档。
- **学完你能**：为代码补齐测试与文档，每次改动都「实现—验证—审查」。

#### 09 · Git 集成：提交、分支与 PR
- **目标**：让它写提交信息、管分支、建 PR，并理解它的安全边界。
- **学完你能**：用自然语言完成日常 Git 操作，知道哪些破坏性操作它不会擅自做。

#### 10 · Slash 命令与自定义命令
- **目标**：掌握内置斜杠命令，把常用流程封装成自定义命令。
- **学完你能**：用 `/command` 一键触发重复工作，打造专属工具箱。

---

### 规模化篇 · 从一个代理到一支队伍

#### 11 · 子代理 Subagents 与并行研究
- **目标**：理解子代理；学会一句话同时开多个子代理独立调查再汇总。
- **学完你能**：面对大型搜索/多模块任务时并行拆分，省主上下文、提效率。
  - 例：`用独立子代理并行研究认证、数据库、API 三个模块`

#### 12 · Agent Team：多代理协作
- **目标**：理解 Agent Team（多个独立 Claude 会话互相通信、共享任务列表）与 Subagent 的区别。
- **学完你能**：为「需要讨论协作」的复杂工作组建一支会自我协调的代理小队。

#### 13 · Git Worktrees：多任务并行不打架
- **目标**：用 `claude --worktree` 给每个并行会话开独立工作区，改文件互不冲突。
- **学完你能**：同时推进多个功能/修复分支，互不干扰，干完再合并。

#### 14 · 后台会话与车队监控：claude agents
- **目标**：把任务丢后台跑，用 `claude agents`（agent view）一屏监控所有后台会话状态。
- **学完你能**：同时派发多个后台任务，一眼看清谁在跑、谁要你拍板、谁完成了。

---

### 自主运行篇 · 让它自己跑起来

#### 15 · /loop：让任务循环跑
- **目标**：用 `/loop` 让一段提示反复执行，可固定间隔（`/loop 5m ...`）或让它自定节奏。
- **学完你能**：让它持续盯着某件事（如「检查部署是否完成并告诉我」）直到你喊停。

#### 16 · /goal：目标导向，跑到满足条件为止
- **目标**：用 `/goal` 设定「完成条件」，让它跨多轮自己干，直到条件满足。
- **学完你能**：下达「`/goal test/auth 全过且 lint 干净`」这类目标，让它自己折腾到达标。

#### 17 · Monitor 工具与定时任务：盯后台不轮询
- **目标**：用 Monitor 工具让它监听后台进程（CI、日志、dev server），事件来了即时反应，不靠 sleep 轮询；了解定时任务（cron）。
- **学完你能**：让它实时盯着训练/CI/日志，出事自动接手处理。

#### 18 · Hooks + Skills + Automation：把流程固化
- **目标**：用 Hooks 在工具调用前后插自动检查，用 Skills 沉淀可复用工作流，用 Automation 定时自动跑。
- **学完你能**：把团队规范和重复流程固化，让它从交互工具变成持续运行的助手。

---

### 远程与无头篇 · 脱离终端干活

#### 19 · 远程控制：Web / 手机 App / --remote 并行云任务
- **目标**：用 `claude --remote "..."` 从终端开云端会话；了解 Claude Code on the web 和手机 App。
- **学完你能**：连发多条 `--remote` 并行跑云任务，通勤路上用手机也能盯进度、发指令。

#### 20 · 无头模式与 CI：claude -p、GitHub Actions、SDK
- **目标**：用 `claude -p "query"` 做脚本/CI 自动化；接入 `anthropics/claude-code-action@v1`；了解 Agent SDK 编排。
- **学完你能**：在 CI 里让它自动 review PR、改代码，或用 SDK 把它嵌进自己的程序。

#### 21 · MCP 与外部工具集成
- **目标**：认识 MCP（Model Context Protocol），接入外部工具与数据源（数据库、API、文档、GitHub）。
- **学完你能**：给它接上外部工具，让它能查你的数据库、调你的服务、读你的 issue。

---

### 实战篇 · 真实项目交付

#### 22 · 综合实战与最佳实践心法
- **目标**：串起全书能力，在真实项目里跑完整闭环（搭项目 / 陌生库修 Bug 重构）；总结结构化输入、上下文治理、会话管理等心法。
- **学完你能**：形成自己的「人机协作」工作习惯，把 Claude Code 真正变成生产力。

## ✅ 学完整本小册，你将能够

- 让 Claude Code **单兵**完成日常开发任务（配置、搜索、改码、测试、Git）；
- 让它**并行**作战（子代理 / Agent Team / Worktrees / 后台车队）；
- 让它**自主**运行（/loop、/goal、Monitor、Automation）；
- 让它**远程/无头**干活（手机、网页、CI、SDK）；
- 在真实项目中安全、高效地与它协作，而不是「让 AI 写完拉倒」。

---

## 📌 学习建议

1. **动手优先**：每章配可运行 Demo（`xx-demo/`），别只看不练。
2. **循序渐进**：入门进阶务必跑通再上规模化/自主运行，后面能力都建立在前面理解之上。
3. **带着真实项目**：学到规模化篇后，把方法用到手头项目里，印象最深。
