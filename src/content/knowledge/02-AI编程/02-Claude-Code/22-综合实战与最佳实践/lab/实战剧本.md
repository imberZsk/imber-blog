# 端到端实战剧本（照着发给 Claude Code）

## 剧本 A：从零搭一个带测试的小项目
1. 起草 CLAUDE.md：约定语言/缩进/注释/测试命令（第05章）
2. 进 Plan Mode，要实现计划，先别写代码（第06章）
3. 按计划分步实现，每步审查 diff（第03/04章）
4. 补测试覆盖边界，跑测试全绿（第08章）
5. 开分支、提交、提 PR（第09章）

## 剧本 B：陌生代码库修 Bug + 重构
1. 要仓库概览，讲清核心流程（第07章）
2. 用独立子代理并行研究相关模块（第11章）
3. 追踪完整代码链路（第07章）
4. Plan Mode 诊断根因，先别改（第06章）
5. 修复 + 补可复现的测试，跑测试全绿（第07/08章）
6. 加 PostToolUse hook 自动 lint + GitHub Action 自动审查（第18/20章）

## 闭环口诀
立规矩 → 先规划 → 分步实现+审查 → 补测试验证 → Git收尾 → 加自动化护栏
