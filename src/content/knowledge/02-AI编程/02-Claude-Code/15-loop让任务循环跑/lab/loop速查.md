# /loop 速查（别名 /proactive）

## 三种用法
| 写法 | 含义 |
| --- | --- |
| `/loop 5m <提示>` | 固定每 5 分钟跑一次 |
| `/loop <提示>` | 动态间隔，它自定节奏（更省 token，推荐） |
| `/loop` | 跑内置维护检查，或项目 .claude/loop.md 里的提示 |

## 可直接发的场景
- /loop 5m 检查生产部署状态，成功或失败都立刻告诉我
- /loop 检查这个 PR 的 CI，过了告诉我；有 review 评论就逐条帮我处理
- /loop 3m 看训练日志最后 50 行，有报错或异常就总结给我

## 选型口诀
- 不确定频率 → 用动态（不加时间）
- 明确要"每 X 分钟" → 固定间隔
- 内容尽量只读；办完即停，别空转
