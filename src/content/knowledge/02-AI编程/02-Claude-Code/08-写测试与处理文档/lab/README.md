# Demo 08 · 补测试与补文档实战

一个**没有测试、也没有文档**的小模块（密码强度校验）。用来练习本章两个四步法：补测试、补文档。

## 文件说明
- `password.js`：密码强度校验，函数没注释、没测试，正等你补。

## 练补测试（四步法）
```
1.（找空白）@password.js 里哪些函数没有测试覆盖？
2.（生成）为 password.js 写测试（用 node 自带 assert，输出到 password.test.js）。
3.（补边界）补充边界用例：空字符串、纯数字、超长、刚好达到/差一位达标。
4.（跑并修）运行 `node password.test.js`，修复任何失败。
```

## 练补文档（四步法）
```
1.（找空白）@password.js 里哪些函数没有 JSDoc？
2.（生成）给它们补 JSDoc，含参数说明和一个使用示例。
3.（增强）补充边界说明（如各规则的具体含义）。
4.（校验）检查注释是否符合「每个函数和参数都要注释」的规范。
```
