# 11 章 Demo · 一页纸速查卡

本章是经验总结章，Demo 就是一张可以打印贴墙的速查卡。

## 文件

```
12-最佳实践与常见坑-demo/
├── README.md
└── 速查卡.md        # 三原则 + 必做清单 + 五反模式 + 心智模型 + 排错口诀
```

## 怎么用

- **写新技能前**：扫一眼「三条核心原则」和「必做清单」。
- **技能出问题时**：看底部「出问题先问」的排错口诀。
- **review 别人的技能时**：对照「五大反模式」逐条检查。

建议直接打印出来贴在显示器边上，写技能时随时瞄一眼。

## 你会收获什么

- 把全书重点压缩成一页，不用每次翻书。
- 一份能用来 review 技能的对照标准。

## 可视化规格

> VISUAL_STRATEGY：思维导图（Mindmap）
> DIAGRAM_DESCRIPTION：中心节点为“11 章 Demo · 一页纸速查卡”，一级分支使用本文主要章节，至少覆盖核心概念、适用场景、实现要点、选型取舍和常见误区。
