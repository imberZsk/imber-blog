# 代码审查清单

逐项核对，每项给出「通过 / 有问题 / 不适用」。

## 安全
- [ ] 是否有 SQL 注入风险（字符串拼接 SQL）？
- [ ] 是否硬编码了密钥、密码、token？
- [ ] 用户输入是否做了校验/转义？

## 正确性
- [ ] 边界条件（空值、0、负数、超长输入）是否处理？
- [ ] 异常是否被静默吞掉（空 catch）？
- [ ] 是否有资源泄漏（文件/连接没关闭）？

## 规范
- [ ] 命名是否清晰、一致？
- [ ] 关键逻辑是否有必要的注释？
- [ ] 是否有明显重复代码可以提取？

## 测试
- [ ] 关键逻辑是否有对应的测试？
