# 产品化与 AI 公司（01） - 学习指南

> AI Agent Company 不是让多个 Agent 自由聊天，而是把目标、角色、任务、执行、审批、预算和审计组织成可运营系统。

## 学习目标

- OPC 市场、产品、交付、销售、客服和财务闭环
- 人类创始人与 Agent 的责任边界
- Company、Goal、Board、CEO 与组织架构
- Issue、Delegation、Heartbeat、Session 与 Adapter
- Approval、Budget、Identity、Secrets 与 Audit Trail
- 产品发现、MVP、成功指标与非功能质量
- AI 驱动研发、发布、运营与反馈闭环

## 实践方法

1. 先验证真实用户问题与付费意愿。
2. 用最小业务闭环定义角色、任务和交付物。
3. 再建设控制平面、执行策略和审批预算。
4. 最后把研发、发布、运营和知识回流连接起来。

## 常见误区

- 先堆 Agent 数量，再寻找用户问题，最终只有演示没有可交付价值。
- 让同一个 Agent 同时提出方案、批准预算、发布生产并评价结果，失去职责分离。
- 用调用次数和自动化率代替任务成功率、首次价值时间、留存和付费等产品指标。

## 学完验收

- 能说明哪些决策必须由人类负责。
- 能画出 Goal → Issue → Agent → Artifact → Review 的链路。
- 能设置预算、权限、审批和审计边界。
- 能用用户指标而不是 Agent 活跃度判断产品价值。
