# 07 - 跨会话记忆：跑两次，它就认得你了

本 demo 配套小册第 07 章。一个有**文件记忆**的 Agent：第一次见你时它不认识你，问出你的偏好后写进记忆文件；**第二次启动时自动加载记忆，直接认出你**。

这就是"上下文（短期）"和"记忆（长期）"的本质区别的活演示。

## 怎么跑

无需 API Key，直接跑。**关键是连跑两次：**

```bash
python agent.py    # 第一次：它不认识你，会"学习"并记下你的偏好
python agent.py    # 第二次：它从记忆文件认出你，直接用你的偏好
```

第一次输出大致是：

```
🤖 你好，我们好像是第一次见面。你写代码偏好哪门语言？
（学习到偏好：TypeScript，已写入记忆文件 memory/）
```

第二次输出大致是：

```
🤖 欢迎回来！我记得你偏好 TypeScript，这次还用它对吧？
```

跑完后会生成 `memory/` 目录，里面有 `MEMORY.md`（索引）和一条记忆文件。想"失忆重来"就删掉 `memory/` 目录再跑。

## 看点

1. **索引 + 分文件结构**：打开 `memory/MEMORY.md` 和那条记忆文件，对照第 07 章的格式。
2. **启动加载 vs 按需写入**：`load_memory` 在启动时读索引，`save_memory` 在学到新东西时写文件。
3. **记忆条目带 description**：看记忆文件的 frontmatter，理解它为什么重要。
4. 改改记忆文件内容再跑第二次，看 Agent 的反应——记忆是真从文件读的，不是写死的。
