# Claude Code（2）- 安装与第一次对话

> 本章目标：完成安装、登录认证，在终端里跑通第一次对话。
> 学完你能：在自己电脑上启动 Claude Code，让它读懂一个项目并回答你的第一个问题。

---

# 一、安装前你需要什么

- 一个**终端**（macOS 的 Terminal/iTerm、Windows 的 PowerShell/WSL、Linux 的任意 shell 都行）。
- **Node.js 18+**（Claude Code 通过 npm 分发）。不确定有没有？终端敲：

```bash
node --version
```

如果显示 `v18.x` 或更高就行；提示「command not found」就先去 nodejs.org 装一个。

---

# 二、安装

最通用的方式是用 npm 全局安装：

```bash
npm install -g @anthropic-ai/claude-code
```

装完验证一下：

```bash
claude --version
```

能打印出版本号，就装好了。

> 💡 macOS 上如果报权限错误（EACCES），别急着 `sudo`。更干净的办法是用 nvm 管理 Node，或者按提示配置 npm 的全局目录。`sudo npm install -g` 容易留下权限混乱的坑。

---

# 三、第一次启动与登录

进入**任意一个项目目录**（重点：Claude Code 是「在某个项目里」工作的），然后直接敲 `claude`：

```bash
cd ~/code/my-project   # 换成你自己的项目
claude
```

第一次启动会引导你**登录认证**。两种常见方式：

1. **Claude 账号登录**（推荐新手）：浏览器弹出授权页，点同意即可。
2. **API Key**：如果你有 Anthropic API Key，可以配成环境变量 `ANTHROPIC_API_KEY`。

认证成功后，你会进入一个交互式对话界面，光标在等你输入。**这就是你和 Claude Code 对话的地方。**

---

# 四、跑通第一次对话

别急着让它改代码。第一次，先让它「读懂」你的项目——这是最安全、最能建立信任的开场。试试这句：

```
给我这个仓库的概览
```

它会做几件事（你能在屏幕上看到每一步）：

1. 列目录、读关键文件（README、package.json 等）；
2. 总结出：这是个什么项目、用了什么技术栈、目录怎么组织。

再追问一句，体会它「带着上下文回答」的能力：

```
这个项目是怎么启动的？入口在哪？
```

它会基于刚才读到的内容，直接告诉你启动命令和入口文件——而不是泛泛地讲「一般来说……」。

> ✅ 跑到这一步，你就完成了第一次对话。恭喜，你已经会用 Claude Code 的「只读模式」了。

---

# 五、几个一开始就该知道的操作

- **退出**：输入 `/exit` 或按 `Ctrl+C` 两次。
- **看能用哪些斜杠命令**：输入 `/`，会列出所有可用命令（第 10 章细讲）。
- **多行输入**：想换行而不发送，用 `\` 结尾或按对应快捷键（界面里有提示）。
- **让它停下**：它正在干你不想要的事？按 `Esc` 打断。
- **继续上次对话**：下次进项目想接着聊，用 `claude --continue`（接最近一次）或 `claude --resume`（挑一个历史会话）。

---

# 六、常见错误

**错误 1：在家目录或一个超大目录里启动它**
Claude Code 会以当前目录为「项目根」。在 `~/` 或硬盘根目录启动，它面对成千上万个文件会很懵。→ **永远在具体项目目录里启动。**

**错误 2：第一次就让它改核心代码**
你还没建立对它的判断，它也还没摸清你的项目。→ 先用只读问题热身（概览、查找、解释），再逐步放开。

**错误 3：装好后用 `sudo claude`**
没必要，还可能引发权限和配置错乱。正常用户身份运行即可。

**错误 4：以为它能记住跨项目的一切**
每个项目的对话上下文是相对独立的。换项目 = 换一个工作现场。

---

# 七、最佳实践

1. **用版本管理 Node**：用 nvm/fnm 管理 Node 版本，避免全局 npm 权限坑。
2. **项目里先跑 `git init`**（如果还没有）：后面它改代码时，你能用 `git diff` 随时看改了啥，安全感拉满。
3. **第一次对话只读不写**：概览 → 查找 → 解释，三连热身。
4. **认证信息别外泄**：API Key 放环境变量，别写进会提交的文件里。

---

# 八、总结

- 安装：`npm install -g @anthropic-ai/claude-code`，`claude --version` 验证。
- 启动：进**具体项目目录**，敲 `claude`，首次会引导登录。
- 第一次对话：用「给我这个仓库的概览」这类**只读问题**热身。
- 记住几个救命操作：`Esc` 打断、`/exit` 退出、`--continue` 接着聊。

# 动手实践：Demo 02 · 一个用来练手的迷你项目

这是一个**故意做得很小**的示例项目（一个命令行待办清单）。它的用途是：让你装好 Claude Code 后，有个真实但不复杂的项目可以练习「第一次对话」。

## 怎么用

1. 在本目录启动 Claude Code：
   ```bash
   cd 03-安装与第一次对话-demo
   claude
   ```
2. 用这些**只读问题**热身（不会改任何代码）：
   ```
   给我这个仓库的概览
   这个项目是怎么运行的？入口在哪？
   解释 @todo.js 里 addTodo 函数的逻辑
   ```
3. 感受它「读懂项目后带着上下文回答」的能力。

## 项目本身怎么跑（可选）

```bash
node todo.js add "学习 Claude Code"
node todo.js list
```

数据存在同目录的 `todos.json`（首次运行自动创建）。
