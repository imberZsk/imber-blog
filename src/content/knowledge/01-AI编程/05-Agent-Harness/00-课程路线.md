# 《AI Agent Harness》学习小册 · 学习路线与目录

> 一句话说清这本小册讲什么：**大模型（LLM）本质上只会"预测下一个字"，而 Harness 就是把它包装成能读文件、能调工具、能记事、能自己干活的"智能体（Agent）"的那层外壳。** 这本小册带你从看懂它，到亲手造一个。

## 这本小册写给谁

- 用过 Claude Code / Cursor / 各种 AI Agent，但好奇"它到底是怎么跑起来的"
- 想自己动手做一个 Agent，而不只是调别人封装好的 API
- 有基本编程经验（能看懂 Python），但不要求懂 AI 原理

只要你会写 `print("hello")`，就能跟下来。

## 你会得到什么

学完这本小册，你能：

1. 讲清楚一个 AI Agent 从"收到任务"到"完成任务"中间到底发生了什么
2. 从零写出一个能调用工具、能管理上下文、有记忆的 mini Agent
3. 看懂 Claude Code 这类成熟 harness 的设计取舍，并知道生产化要补哪些坑

---

## 学习路线总览

我们把整条路线分成 4 个阶段，像盖房子一样：先看懂图纸 → 搭骨架 → 装功能 → 精装修。

```
阶段一：入门篇 —— 看懂图纸
  搞清楚 Harness 是什么、为什么需要它、那个核心循环长什么样

阶段二：核心机制篇 —— 搭骨架 + 装功能
  工具调用、系统提示词、上下文管理、记忆、权限安全
  （Harness 的"五脏六腑"都在这里）

阶段三：进阶篇 —— 高级装修
  子代理编排、扩展机制（Hooks / Skills）

阶段四：实战篇 —— 交付入住
  从零搭一个能用的命令行 Agent，并补齐生产级的坑
```

每一章都遵循同一个节奏：**先讲明白概念 → 给可运行示例 → 列常见坑 → 总结最佳实践**，并配一个 `xx-demo/` 让你动手跑。

## 详细章节目录

### 🟢 阶段一：入门篇（必读，别跳）

#### 01 · 什么是 Harness：从"会聊天的模型"到"会干活的智能体"
- **学习目标**：理解 LLM 和 Agent 的本质区别；知道 Harness 在中间扮演什么角色；建立"模型是大脑，harness 是身体"的心智模型。
- **Demo**：`01-llm-vs-agent-demo/` —— 同一个问题，分别用"裸 LLM 调用"和"带 harness 的调用"对比，直观看到差别。

#### 02 · Agent 的心脏：理解核心循环（Agent Loop）
- **学习目标**：吃透 Agent 最核心的运转机制——"思考 → 行动 → 观察 → 再思考"的循环；明白它为什么是循环而不是一条直线；知道循环何时停止。
- **Demo**：`02-agent-loop-demo/` —— 把循环的每一步都打印出来，看着 Agent 一轮一轮地推进任务。

#### 03 · 动手搭一个最小 Harness（50 行代码跑通第一个 Agent）
- **学习目标**：把前两章的概念变成能跑的代码；用最少的代码量获得"我造出了一个 Agent"的成就感。
- **Demo**：`03-minimal-harness-demo/` —— 给 Agent 一个文件夹，让它能回答"这里面有什么文件"。

### 🟡 阶段二：核心机制篇（Harness 的五脏六腑）

#### 04 · 工具调用进阶：让 Agent 优雅地使用多个工具
- **学习目标**：从"能调一个工具"升级到"管理一组工具"；学会写清晰的工具 schema 和描述；处理多工具选择、调用出错、参数注入安全。
- **Demo**：`04-tools-demo/` —— 一个带"读文件 / 算数 / 查天气（mock）"三个工具的 Agent，观察它如何自主选工具。

#### 05 · 系统提示词与指令设计：给 Agent 立规矩
- **学习目标**：理解 system prompt 为什么是 harness 里"性价比最高的控制手段"；学会分层组织指令；知道指令冲突时谁说了算。
- **Demo**：`05-system-prompt-demo/` —— 同一个 Agent，换不同 system prompt，看行为如何天差地别。

#### 06 · 上下文管理：和"窗口装不下"作斗争
- **学习目标**：理解 context window 是什么、为什么会满、满了会怎样；掌握截断、压缩（compaction）、摘要等常见策略。
- **Demo**：`06-context-demo/` —— 模拟一段超长对话，演示上下文压缩前后的对比。

#### 07 · 记忆系统：让 Agent 跨会话记住事情
- **学习目标**：区分"上下文"和"记忆"；理解基于文件的持久化记忆怎么做（就是本 harness 用的方式）；知道什么该记、什么不该记。
- **Demo**：`07-memory-demo/` —— 一个会把"用户偏好"写进记忆文件、下次启动自动加载的 Agent。

#### 08 · 权限与安全：别让 Agent 把你的电脑删了
- **学习目标**：理解 Agent 自主性带来的风险；掌握权限模式、危险操作确认、把外部内容当"不可信数据"等防护思路。
- **Demo**：`08-permission-demo/` —— 给删除/写文件等操作加上确认拦截，演示一次"被拦下来的危险命令"。

### 🟠 阶段三：进阶篇

#### 09 · 子代理编排：让 Agent 指挥 Agent
- **学习目标**：理解为什么要拆出 sub-agent（隔离上下文、并行干活）；掌握主代理与子代理的协作模式。
- **Demo**：`09-subagent-demo/` —— 主 Agent 把"分别总结 3 个文件"的活并行派给 3 个子 Agent。

#### 10 · 扩展机制：用 Hooks 和 Skills 增强而不改内核
- **学习目标**：理解如何在不动 harness 核心代码的前提下扩展能力；搞懂 Hooks（拦截/审计）和 Skills/命令（封装可复用能力）。
- **Demo**：`10-hooks-skills-demo/` —— 给 Agent 加一个"每次调用工具自动记日志"的 hook。

### 🔴 阶段四：实战篇

#### 11 · 综合实战：从零构建一个可用的命令行 Agent
- **学习目标**：把 01–10 的知识串成一个完整作品；设计架构、组装循环与工具、加上交互式命令行界面。
- **Demo**：`11-cli-agent-demo/` —— 一个你能在终端里真正对话、让它帮你操作文件的 mini "Claude Code"。

#### 12 · 走向生产：流式、重试、自验证与可观测性
- **学习目标**：补齐 demo 到产品之间的坑——流式输出、错误重试、让 Agent 自己验证结果、成本/token 优化、日志与可观测性。
- **Demo**：`12-production-demo/` —— 给第 11 章的 Agent 加上重试、流式输出和自动验证。

## 关于 Demo 的统一约定

- **语言/技术栈**：统一用 Python 3 + Anthropic 官方 SDK（`anthropic`），代码追求"读起来就懂"。
- **能离线就离线**：纯机制类演示（如循环结构、上下文压缩）尽量用 mock 或本地逻辑，不依赖联网，方便随时跑。
- **需要 API Key 的会标注**：真正调用模型的 demo 会在 README 里明确写出来，并给出 mock 降级方案。
- **每个 demo 配 README**：说明"这个 demo 演示什么、怎么跑、预期看到什么"。

## 给学习者的建议

1. **01–03 别跳。** 这三章是地基，跳了后面会处处卡壳。
2. **先跑 demo，再回头抠细节。** 看到效果再读原理，吸收最快。
3. **04–08 可按需选读。** 但建议至少通读一遍，知道每块在干嘛。
4. **最重要的一步：动手改 demo。** 把示例里的工具换成你自己的，才算真懂。
