# 五要素提示词填空模板

把下面的模板复制走，按需填空，就能搭出一个结构清晰的专业提示词。
不是每个空都必须填，但每次都对着过一遍，确保不漏关键部分。

---

## 空白模板（复制这个去填）

```
【角色】你是一名 ______（资深/专业身份），擅长 ______。

【任务】请帮我 ______（一个明确的动词 + 要做的事）。

【上下文】
- 背景：______（我是谁 / 做什么的）
- 受众：______（给谁看）
- 场景：______（用在哪里）
- 材料：______（相关原文 / 数据，如果有）

【输出格式】
- 形式：______（列表 / 表格 / 分段 / JSON…）
- 长度：______（多少字 / 几条）
- 结构：______（要不要小标题 / 先结论后展开）

【约束】
- ______（不超过 X 字 / 不要术语 / 不要编造 / 语气要求…）
- ______
```

---

## 范例一：电商客服回复

```
【角色】你是一名经验丰富的电商金牌客服，耐心、共情能力强，擅长安抚情绪并高效解决问题。

【任务】请根据顾客发来的消息，生成一条客服回复。

【上下文】
- 背景：我们是一家卖手工烘焙饼干的网店，主打口碑和回头客。
- 受众：刚收到货、可能带着情绪的顾客。
- 材料（政策）：质量问题包退换并补一张 5 元券；物流问题可催单但无法改变时效。

【输出格式】
- 形式：直接输出一条可发给顾客的回复，不要额外解释。
- 长度：100 字以内。
- 结构：先共情安抚 → 再给具体解决方案 → 结尾一句暖心话。

【约束】
- 语气真诚口语化，像朋友，不要官腔，不要用「亲」。
- 不要承诺政策之外的事。
- 顾客情绪激动时，先道歉安抚再说方案。

顾客消息：
"""
{在这里粘贴顾客消息}
"""
```

## 范例二：产品卖点文案

```
【角色】你是一名擅长写转化文案的资深营销文案，文字简洁有力、直击痛点。

【任务】请帮我为下面这款产品写一段卖点文案。

【上下文】
- 背景：一款面向老年人的健康监测手环，主打「操作极简、一键呼救」。
- 受众：给父母选礼物的子女（不是老人本人）。
- 场景：电商详情页顶部的核心卖点区。

【输出格式】
- 形式：一句主标题 + 3 条卖点，每条卖点一句话。
- 长度：总共 120 字以内。
- 结构：主标题要有情感冲击，卖点要具体可感。

【约束】
- 站在子女「想尽孝、又怕父母不会用」的心理写。
- 不要堆砌参数，说人话。
- 不要用「最」「第一」等绝对化用词。
```

## 范例三：技术文章大纲

```
【角色】你是一名资深技术博主，擅长把复杂概念讲得通俗易懂。

【任务】请帮我列一篇技术科普文章的大纲。

【上下文】
- 背景：文章主题是「什么是缓存，以及为什么它能让网站变快」。
- 受众：刚入行、没什么后端经验的初级开发者。
- 场景：发布在公司技术博客，用于科普引流。

【输出格式】
- 形式：分层级的大纲（一级标题 + 每节要点）。
- 长度：3~5 个一级标题，每个标题下 2~3 个要点。
- 结构：从「是什么」到「为什么」再到「举个例子」。

【约束】
- 每个一级标题都要能用一个生活类比来讲。
- 不要写正文，只要大纲。
- 避免一上来就堆术语。
```
