# Claude Code 心法速查卡

## 六大心法
1. 上下文 > 提示技巧：结构化输入（目标+@文件+边界+验证）
2. 复杂任务先规划再执行（Plan Mode）
3. 让它参与完整闭环：实现→测试→跑→lint→审查
4. 会话管理 = 上下文治理：一会话一主线，勤 /clear，脏活给子代理
5. 规则可执行、流程可沉淀：命令/Skill/Hook/Automation
6. 按风险放手，按规模选工具

## 能力版图（一句话记牢）
CLAUDE.md=始终在的上下文 | Skills=按需知识/工作流 | MCP=外部连接 |
Subagents=隔离 | Hooks=自动化

## 选工具速查
- 并行：要结果→Subagent；要协作→Agent Team；文件隔离→Worktree；长任务→后台+claude agents
- 自主：周期查→/loop；干到成→/goal；实时盯→Monitor；定时无人值守→Automation
- 远程无头：脚本→claude -p；团队CI→GitHub Action；产品集成→SDK；离开电脑→web/手机

## 安全红线
AI产出必审查 | 高危操作设防 | 密钥进环境变量 | 外部数据当不可信
