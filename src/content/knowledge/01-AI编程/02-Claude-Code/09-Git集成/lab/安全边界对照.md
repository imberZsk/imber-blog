# Git 安全边界对照表

| 操作 | 默认行为 |
| --- | --- |
| 推到 main/master | ❌ 不直接推，默认推新分支（除非你明确要求） |
| `git push --force` | ❌ 不擅自做，需明确授权 |
| `git reset --hard` | ❌ 不擅自做，需明确授权 |
| `git clean -f` | ❌ 不擅自做，需明确授权 |
| `git branch -D` | ❌ 不擅自做，需明确授权 |
| 提交改动 | ⏸ 通常等你发话才提交 |
| 遇到 .env / 密钥文件 | ⚠️ 提交前提醒你 |
| 改 git config | ❌ 不碰 |

> 口诀：可能丢代码 / 影响别人的操作，决定权留给你。这是保护，不是缺陷。
