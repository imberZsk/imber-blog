# 后台车队调度清单

## 第一步：派发后台任务（适合"能自己跑一大段"的活）
- 让一个会话去补一整套测试
- 让另一个去修某个已诊断清楚的 bug
- 配合 worktree（第13章）给每个任务独立工作区，互不打架

## 第二步：打开监控面板巡检
```bash
claude agents
```
状态对照：
- 🟢 正在跑     → 不用管，让它继续
- 🟡 需要输入   → 进去给指示再让它跑
- ✅ 已完成     → 查收，审查它的产出

按 Esc 退出面板。

## 第三步：只在必要时介入
- 让它们自己跑，卡在"需要输入"时你再处理
- 控制并发数量，匹配你能照看的范围

## 注意
- agent view 目前是研究预览特性，需在交互式终端打开
- 后台 ≠ 丢了不管，要定期巡检
