# 远程控制速查

## 从终端开云端会话
claude --remote "修复 auth.spec.ts 里那个 flaky 测试"

## 多个云任务并行（连发多条，各自独立）
claude --remote "修复 flaky 测试"
claude --remote "更新 API 文档"
claude --remote "重构 logger 为结构化输出"

## 多设备接力节奏
终端/网页派活 → 离开电脑 → 手机巡检+决策 → 回电脑收尾

## 本地 vs 远程
- 长任务、想关电脑、想腾本地资源 → 远程
- 强依赖本地环境/未推送代码 → 本地
- 远程任务：指令要更自包含（目标+边界+验证一次说清）
- 需要的代码先推上去，云端基于仓库
