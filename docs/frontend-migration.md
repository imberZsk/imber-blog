# 前端功能整合

源目录：`/Users/imber/Desktop/ai-lab/projects/imber-frontend`（只读）。
目标：当前 `imber-blog` 工作树。所有页面继续使用博客的导航、颜色令牌、主题切换与基础组件。

## 入口和范围

| 页面 | 功能 |
| --- | --- |
| `/lab` | 三类实验入口；首页也保留分类预览，主导航新增「实验室」 |
| `/lab/animation` | 源项目已发布的 22 个动画入口、名称搜索、视频懒加载及悬停预览 |
| `/lab/animation/*` | GSAP / Framer Motion 原始演示、原有源码查看和复制；保留 Exit / Timeline 默认入口 |
| `/lab/3d` | 六类场景的关键词检索和预览 |
| `/lab/3d/*` | 基础场景、立方体环境、天空盒、全景看房、数据地球、FBX 角色动画 |
| `/lab/docs` | 101 篇原分类笔记的标题/正文检索与分类筛选 |
| `/lab/docs/*` | 原 Markdown 阅读、同分类导航、文章目录、本地媒体和站内链接 |

源项目仅有空 JSX 的 Fade、SVG 和 Framer Parallax 占位页没有作为功能入口迁入。
原项目两个空 Markdown 文件仍保留，阅读时明确显示原文尚未填写正文。
原文内容未经改写；图片、视频、贴图、GLTF、FBX 和 Draco 解码器均保存在 `public/frontend-lab/`。
原示例引用的第三方远程图片、视频和外部编辑器 iframe 继续依赖对应原服务。

## 运行和维护

```sh
pnpm install
pnpm dev
```

工作树已安装独立依赖，不再链接源目录的 `node_modules`；新增 Three.js 及其类型依赖。
`next.config.ts` 会识别工作树与依赖的共同根目录，并将应用配置实际传给 Sentry 包装器。

新增功能只使用实验室内的专用组件。动画 CSS 限定在实验室，源码弹窗复用博客 Button。
Three.js 画布跟随容器尺寸，离开页面时停止循环、断开观察器并释放 GPU 资源；异步模型回调也检查卸载状态。
文档媒体改写只处理 Markdown AST 的真实 HTML 媒体节点，不执行正文内的代码示例；文件读取只接受文章清单中的路径。
